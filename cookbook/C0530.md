# C0530 — Lever-removal moves from 3.40 cracks: in-place RMW, % 2^k, derived-pointer reuse, short counters
tags: levers,delever,pins,birthing-boost,sched1,cse · date: 2026-10-21 · phase/task: 3.40/T10 · origin: P3.40 T9/T10 summaries

Lever-removal moves byte-proven in the 3.40 T9/T10 cracks; addenda to the C0505 catalog (moves already there: 16-bit locals R31, both-arms tie split R39, `&&` store-flag R37, keepalive-is-a-return).

- **In-place read-modify-write kills the birthing boost.** An addPrim-style "tag pinned $4" pin falls when the update is spelled `pv = *p; pv &= m; pv |= x; *p = pv;` (one death, three sets on one local): sched1's `birthing_insn_p` boost needs a single-set local (C0434, C0391). Siblings func_80015D4C, func_801AADA8 carry the same pin (3.40 T10).
- **Pinned `% 2^k` result:** write the remainder in place on the target local (`t = src; t %= 2^k;` shape) and reuse the source local later; the pin goes (3.40 T10).
- **Keep a head set alive through cse1 by reusing a later local as the derived pointer** instead of a fresh temp (func_8013F350, 3.40 T9). Related: C0505 named derived pointer (`find_best_addr`).
- **Short loop counters** (`s16`/`u8` counter) drop `+ 0` copies and the pins that held them (func_8016A290, func_80166690, 3.40 T9).
- **A 16-bit result var** removes sched1's birthing boost and a local-alloc tie at once (func_8012E364, `s16 d`, 3.40 T9); widths per C0505.
