# Retiring a generated block in a hand-edited header

**Move (3.45 T6.c1).** To retire a generator from a block in a hand-edited header (H1: a generated block is never hand-edited):
1. Replace the begin marker with ONE provenance line naming the block, the generator, and the commit it last ran at
   (`git log -1 -S'<a type name in the block>' -- <header>`), plus "generator retired <phase/task>; hand-edited since".
   Then delete the end marker (rule T3).
2. Make the generator refuse to write that path (rc 2 and a message) before it reads or writes anything. Keep pure helpers,
   such as `restruct.splice_t3_defs`, so their selftests still run.
3. Repoint every tool that located the block by its markers to the provenance line. Example: `struct_twins.blocks_of`,
   where a block runs to the line before the next column-0 `/*`. Prove the change neutral with a before/after diff of the
   consumer's output, here the inventory's `block` column.

**Trap.** A comment that quotes the C comment opener and closer (for example "the `/* … */` markers") ends at the quoted
closer. The rest of the line is then parsed as code. Each line-1 header comment in `include/struct_types.h` is included by every TU, so one such
line failed 0/218 at R22. Spell the markers without their delimiters.
