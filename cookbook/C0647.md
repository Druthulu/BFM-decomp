# fold-batch limits on the actor slot: member tokens, nested gaps, RESIDUAL re-stamps, one-line unions

Context: P3.45 T17.c30, applying c28's 83 recipes (61 actor keys via the spawner's kind variant, 22 raw arith) plus the
actor unkD4 union, on a tree that had moved since the judge's snapshot.

- Once any key on a `--fold-batch` line carries a `member:` token, the engine stops mapping common fields onto the
  parent's leaves for the whole line (restruct.py:4986): respell the keys' common-field casts to the actor leaves by
  hand first (1,102 sites), then run the batch (the W2 recipe).
- The engine sees top-level gaps only: extC now nests in `blkDC.f`, so fields of nested-gap variants are placed by hand
  into each token's variant (new variants added there), then the dry run is clean.
- `--fold-batch --write` refuses a dirty src/include/config: commit the hand-respell step (asm identical) first.
- Respelling a nested raw base (`(s32)E->unk64 + 0x20) + 4`) un-covers RESIDUAL ledger entries keyed by the old base
  text: restamp them to the new base (like the C0639 KEPT restamp) until census `uncovered 0`.
- `--write` collapses multi-line member unions of the parent into one line each (header shorter; ledger file_line refs
  shift) and drops member comments (C0643).
- Judge patches made on a snapshot: apply respells by exact text match, then fix drift on the changed lines (here:
  `unk20` -> `unk20.p`, `unkDC` -> `blkDC.f.unkDC`, `unk76` -> `unk76.u`). A field-to-union retype's rename probe can
  find far more uses than the judge estimated (unkD4: 500 lines in 191 files vs ~228); a `.lo`->`.hi` negative control
  proves the asm check sees the respelled reads.
