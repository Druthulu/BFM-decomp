# Cross-address share: the SHARED_FN class header (`share_body.py --bucket cross`)

- Use: give a byte-identical class that sits at more than one address (census flag E, optionally F) one source.
- Form: header `src/shared/<space>/cls_<h[:12]>.h` (`multi/` for cross-space), first comment = provenance (class hash, registry id X_<h12>, generator, commit); body defines `SHARED_FN`; each private copy becomes `#define SHARED_FN <own>` / `#include` / `#undef SHARED_FN`; registry `func: SHARED_FN`, verbose members {binary, vram, name}. Names keyed by class hash, so a rename touches only the `#define` lines and member names.
- Trap: sig files spell names lowercase hex (`func_8017d290`), source writes uppercase; own-name masking must be case-insensitive, and registry member names must use the source spelling (first probe: 2,074 false TEXT-DIFFERS, lowercase members).
- Trap: restruct's default scope is `ov_*`; pass `--only <touched aliases> <header paths>` to `--residue --restamp` / `--check-residue` so src/shared headers are covered.
- Trap: a header-def's ledger keys are (header, SHARED_FN) for lever and type_census sites; verbatim uses binary `shared`.
- Cost: one batch is ~525 s even for 2 classes (census + type_census --sites + restruct); run in the background; build touched binaries first so the gate snapshot is current.
- Red class: all-or-nothing undo (every site, header removed), not ledgered, so S1 violations fall exactly by converted classes.
- Trap (T4.c2, 120-class pilot): a moved body's ledgers re-key to (header, SHARED_FN) in four places the census gates read: (1) restruct rung-S rows: run `--rung S --residue` before `--restamp`, with `--forms P,I,X,M`; (2) tools/argcheck.py definitions(): each `#define SHARED_FN <own>`/`#include` site binds <own> to the header def, located at the including TU (else 75 false unledgered lying); (3) `CAST_*` macro sites are backed only by a `KEPT(<cls>)` entry in the body's latest rung-S row (type_census.py:2066-2084): copy the private copy's row to the header key. A 2-class probe with no such sites proves none of this; probe a class with CAST_* uses and callers.
- Trap (T4.c3): when merging copies' rung-S rows into the header row, ignore `line` except for `KEPT(REINTERP)` (the only entry the gate matches by line); copies' def-relative lines drift by up to ~80, and a line-keyed merge multiplied entries (67 -> 120). Repair an already-committed batch with `share_body.py --rekey-batch <label>` (idempotent via `rekey_of`).
