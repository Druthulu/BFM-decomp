# Asm-label prototypes declare the label, not the C name

- Form: `[extern] <ret> CNAME(<params>) __asm__("SYM");` declares SYM (the jal target); a definition headed by such a
  label (aF*/ta* C names) defines SYM. Join C to the census by SYM, never by CNAME (C0223, C0135).
- Trap 1: a balanced-paren `extern` parser that checks for `;` right after `)` silently drops these prototypes
  (3.44 T5: 3,138 `extern` + 960 bare lines in src/ were invisible).
- Trap 2: `extern W8_ D_80076242_ __asm__("D_80076242");` is an object label, not a function: skip and count it
  (it was 4,678 instances miscounted as declarations named `__asm__`).
- Effect at 3.44 T5: DECL-RET 27 -> 116 names (10,445 -> 34,808 rows); 703 definition instances joined by label;
  "name not in the symtab" 5,988 -> 1,310 declarations, 896 -> 178 definitions.
- Where: tools/sig_evidence.py parse_text / compare_core (commit 1b68e316be); rule in docs/ops/sig-evidence.md Comparison.
