# Scratch git worktree for an in-place tool's reproducer
Tools that write under their own REPO (lift_types --fold, restruct passes) are reproduced on a worktree, never the main tree:
- `git worktree add .run/<phase>/<task>/wt HEAD`; run the worktree's own copy of the tool from inside it.
- The worktree lacks untracked inputs: symlink `tools/reference`, `tools/bin/gcc-2.7.2-{psx,cdk}`, `tools/maspsx`, `tools/psyq`, `.venv`, `asm`, `assets` from the main tree.
- No extract in the worktree: `make check BINARY=<alias>` compiles every .c (the compile check) then stops at the missing `.ld`; that stop is expected.
- Fold reproducer input: when the census `dup_gating.tsv` is header-only, hand-write a one-row TSV for a class from `type_census.json` `dup_layout_classes`.
- Finish with `git worktree remove --force <wt>` and `git worktree prune`.
