## Makefile health-gate traps: `make -n` on .ONESHELL executes; health needs a complete build/ (P38 T1)

- `make -n` on a `.ONESHELL` Makefile whose recipe contains `$(MAKE)` executes the recipe's shell lines (a dry run
  of `tools-health` ran `sdk-dual`'s `rm -rf build/psyq`). Never dry-run such a target.
- A health gate that reads link-map objects (BFM `sig-main`) needs a complete `build/`; run the clean full build
  (R22) first when `build/` may be stale, or the gate goes red on a missing object, not a real defect.
