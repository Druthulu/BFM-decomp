# RET-VOID-READ: widen a void callee whose $v0 callers read (definition + every declaration as one unit)

Context: 3.44 T8.c1, 65 callees, 80,041 declaration lines, 0 bytes moved, 0 ledger rows.

- Readers reach a `void` callee through raw casts `((s32 (*)(s32))f)(a)`; defs and decls agree on `void`, so C0548 rung 1
  is moot: widen the definition and every declaration to the readers' type (one pointer callee took `u32 *`: all readers cast so).
- Tail chains widen together: a widened def ending `g(); return;` needs `g` widened to write `return g(..);`.
- If/else with a tail call in each branch: a `return` per branch moved a branch; one local `r = f(); ... r = g(); return r;`
  is neutral (C0595 shape). Pointer-returning callees: type the local as that pointer, cast once at `return (s32)r;`, no new raw cast site.
- `return 0;` probes that move bytes fall to a `/* $v0 at exit: */` comment (C0567).
- Trap: "asm-only" callees in the census can be SHARED_FN trampoline headers (`src/shared/ov/func_<n>.h`, `void SHARED_FN(...)`
  bound only to its own name); widen their heads too or every includer fails with conflicting types.
- Trap: a scanner that records a declaration's type from comment-masked text can swallow the `#include` lines above it;
  read the type from the source text between the occurrence's offsets (else silent skips, 287 compile failures).
- A reader's RET_AS that now equals the prototype becomes a direct call (objects identical); drop its ret_view_casts row.
