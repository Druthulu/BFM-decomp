# Detecting return-type lies: compare normalised return spellings, not just arity

Situation: the lying-declaration check (`tools/argcheck.py`) compared argument counts only, so a function declared `void`
everywhere and defined returning a value was invisible. The arity reading was 0 while 273 functions lied (3.41 T3).

- Normalise both spellings with `argcheck.norm_ret`: drop `static/extern/inline/__inline__/const`, expand the typedefs of
  the three canonical headers (`include/common.h`, `include/struct_types.h`, `src/shared/engine_types.h`), and fold
  `T*`==`T *`, `unsigned`==`unsigned int`, `signed int`==`int`. Keep `long`, `char` and `signed char` distinct.
- Return rows are opt-in (`scan(..., returns=True)`). Only `type_census` passes it, so the restruct and readability
  callers of `scan` keep their arity-only rows. Each (decl, reason) is one row, with reason `arity` or `return`.
  Exceptions key (callee, def_file, kind) with kind `return`.
- Resolve the definition with norm(ret) in the fleet signature set. An unresolvable one is `cross_binary`, kept apart
  and not counted as a lie (+726 rows over 110 callees at T3).
- `argcheck.result_uses` says whether any caller uses the value, which decides the fix (C0548). It is a heuristic:
  `a ? b : f();` counts as discarded, a comma expression as used, a call hidden in a macro is not seen.
- Census: `decls.lying_reasons` and `decls.return_lies {functions, sites, buckets}`, bucketed by (decl, def, used).
  At T3: arity 0, return 100,266 sites over 273 functions. The site count is large because each per-function TU repeats
  the extern lines.
- The miss it closes: func_8016130C had equal arity everywhere (decl `void`, def `s32` in
  `src/shared/ov/func_8016130C.h`), so the arity check could never see it (C0543).
- Trap: TU-local typedef names (S800D21C4, W4_8018020C, Prim_1412A8) are not expanded, so a few small buckets may differ
  in spelling only. Check them before fixing.
- `type_census --check` counts ledgered return lies as passing (`config/lying_exceptions.tsv`, 3.41 T5).
- Related: C0543 (the return type is a caller byte fact), C0547 (void->int decl can move regalloc), C0548 (the fixing ladder).
