# Clearing return-type lies by fleet: the ladder, and what stays ledgered

3.41 T4 cleared 273 functions / 100,266 lying decl rows down to 19 ledgered callees / 9,302 rows, with 218/218 at every batch.

- Ladder per callee, one unit at a time:
  (a) Rewrite every decl to the def's spelled return type, in place.
  (b) If bytes move, change the def to the type the decls agree on.
  (c) Otherwise revert and add a `config/lying_exceptions.tsv` row (callee, def_file, `return`) citing the observed objdump diff.
- Finding culprits cheaply: apply (a) to every callee, build, then compare object by object against a kept HEAD build. Map the moved objects to callees and run (b) only on those. Gate only whole batches.
- A def-side retype (b) also rewrites every decl that already agreed with the old def, and every non-extern prototype. Otherwise the includers of a shared def fail with "conflicting types". In T4 that came to 45k void→int lines.
- (b) works for `void` defs whose callers use the value (the def becomes `s32`; bytes held for 37 of 38). It also works for an s32 def that every caller drops (func_80139BE0 became `void`).
- Width and sign lies are the ones that stay: u8 vs int (`andi 0xff`), short vs int (`sll/sra 0x10`), u16 (`andi 0xffff`), unsigned vs signed (`sltiu`/`slti`). Both directions move bytes, at the callers or in the def's own extend. These are real byte facts that need an exception row (C0103).
- Edits keep each file's line count (residue ledger rows match by line) and add no casts (the residue gate counts them).
- Rewriter pattern: `.run/P41/T4/fix_ret.py` (argcheck as a library; scratch, not kept).
- Detection: C0552 (how argcheck/type_census find the lies this ladder clears).
