# Scratch-compile a declaration batch against a HEAD baseline, exact per-object commands

- Object set: every build/src/**/*.d that lists an edited file (headers included; common.h-only touches are byte-neutral #defines).
- Commands: `make -n -B BINARY=<b> <objs...>` per binary; keep lines starting `set -o pipefail;` whose `-o build/src/...o`
  is in the set; rewrite `-MF x.d` to `-MF /dev/null` and `-o` to a scratch dir. This carries per-TU flags (-O0 TUs,
  REORDER_TUS, the jtbl_rodata_pads `--derive <binary> --tu <tu>` stage that only main and md_* get, Makefile:914/:1074).
- Baseline: `git archive HEAD src include | tar -x -C <scratch>` and run the same commands from there; sanity-check
  baseline == existing build/ objects.
- Run: split the command list into N shards, one exit-checked serial loop per shard (print FAIL on non-zero rc).
- Trap: `xargs -P16 -I{} bash -c '{}'` produced TRUNCATED objects (fewer functions) on both sides with no error,
  so a cmp could pass on garbage. Never trust a parallel compile that is not exit-checked and baseline==build/ checked.
- Trap: `make clean` deletes build/sig_evidence/census.jsonl; rerun `sig_evidence.py -j 16` before `--compare`.
- 3.44 T5.c2: 2,423/2,423 objects identical for func_80028D9C (2,462 decl lines, 138 RET_AS calls); main then through
  `tools/gate_main.py --assert-baseline` on the committed tree. Tool: `tools/scratch_cmp.py` (3.44 T12).
