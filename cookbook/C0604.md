# Place a global by ELF address: bss symbols lie past the image's file bytes

- main's bss globals are absolute (`A`) symbols in the linked ELF, and their addresses lie past the image's file
  bytes (`_VRAM_BASE` + file size). An "address inside an image's bytes" owner test leaves them unowned
  (3.45 T2.c1 first run: 3,425 globals "address in no image").
- Own a data address by the nearest image at or below it in the binary's own-then-stack order (sig_evidence place()
  order), not by the file-byte range. Functions keep the file-byte test (cls_of).
- A header extern that a binary never references is not in that binary's symtab: "name not in the symtab" for a
  global or callee from a header line is mostly a header included by a binary that does not use the name; count
  unplaced per unique site, not per binary instance, before reading it as a join failure.
- Implemented in tools/struct_twins.py --links (3.45 T2.c1).
