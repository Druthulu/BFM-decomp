# Renaming md-module copies drops their sig instructions unless sig-modules seeds from the symbol files

**Trap (3.43 T9.c14).** The Makefile's `sig-modules` seeded module sigs only from `func_` symbols of the module ELF.
After B4 renamed md copies (guess_IntToBcd_N in md modules), each renamed copy vanished from its module sig (26
instructions each), and tools-health failed on the timeline self-check: fleet instr 13492113 -> 13492009.

**Fix (a2af7fed1c).** The seed step also reads the module symbol file's `// func` names (comment above
MODULE_SIG_JOBS); module totals returned to HEAD values and tools-health went OK.

**Check.** After any batch that names md-module functions, compare fleet instr in the timeline self-check
before/after; a drop by a multiple of a renamed body's size points here. Related: C0572 (tools keyed by placeholder
spelling), C0571 (md-alias rows).
