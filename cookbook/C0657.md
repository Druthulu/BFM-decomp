# Judging SC02/SC04/SC06 views: header tables, false kind edges, pool look-alikes

Context: P3.45 T19 wave A3 judges c1-c7 (525 types, ~2 sources each, per-overlay code; ~15-20 min per 70 types).

- Overlay header: +0x58 is the player action table (player+0x1F0) and +0x5C the small-object kind table, beside +0x60
  actor and +0x64 fx (C0629). A view in a +0x58 handler is the player; in a +0x5C handler a small object, whatever
  offsets it reads (actor-like offsets +0x2/+0x1C/+0x20 are shared by actor, fx and small object: only the table decides).
- Player states: 0x218-sized views in SC02_000/005 are player sub-states installed by func_8016EE94 (player+0x1F8 =
  handler, +0x214 cleared) and dispatched on player->unk214.
- where.py kind edges are noisy: a comment naming a function, an indented nested definition read as a call, and
  `#define SHARED_FN` / `extern` lines all make false edges. Confirm each kind in the asm tables.
- Functions that look unreferenced may be called from shared headers: scan the built overlay binary for `jal` words to
  the address (build/<ov>/<ov>, base from the overlay's link address; T19 c1/w/jal.py).
- Actor tables cut by a data label: the real kind is the word count before the label plus the index (kinds above 1000
  appear, e.g. SC04_002 D_80198034[i] = kind 396+i). See C0651.
- Same kind, several overlays: T17 made per-overlay variant names for one kind (kSC06_020_80181A94, kSC06_022_801859B8 ->
  kSC06_018_80187924, kind 639); the applier merges them into one variant. Same code under different kind ids stays separate.
- A placeholder name can be reused for unrelated objects (a scalar global, another overlay's record): judge per source;
  a source whose object is a plain scalar global is retyped to the scalar, the type's finish comes from its other rows.
- A kind can spawn children of its own kind (kind 823): views through its +0xD0/+0xD4 are its own variant. Actor
  +0xCC/+0xD0 hold model records for some kinds and child actors for others: each kind's state 0 decides.
- Census staleness: a few sources at HEAD cast a different type than sources.tsv says, and deref casts are undercounted
  (C0644): grep src/ for the type before handing a row to the applier.
