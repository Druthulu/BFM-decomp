# Moving held sources whose arithmetic hits a typed pointer field: KEPT-base backing, stale site cache, RMW reschedule

Context: P3.45 T17.c22/c22b moved 778 of 839 held Unkstruct_800B5CB8 sources (arith on actor unk64/unkD4, unsafe, reuse).
- A moved source whose old spelling is the base text of a KEPT(<macro>) ledger entry (`nested:*(s32 *)(((V *)x)->f + K)`)
  leaves that macro unbacked after the respell: `type_census --check-casts` fails (unbacked N). Find with a
  check_casts_verdict wrapper (.run/3.45/t17/c22b/unbacked.py); restamp the KEPT base in the same commit, or revert the key.
- type_census caches sites.jsonl: after any hand respell rerun `type_census ... --sites` before `restruct --check-residue`.
- A field-path respell of a read-modify-write through a typed pointer (`p->unkD4->unk4.val &= m`) can reschedule where
  `*(s32 *)((s32)p->unkD4 + 4) &= m` does not: find it with a cc1 asm diff against a HEAD overlay (overlay needs include/
  and src/shared/; c22b/asmd.sh).
- `make clean` deletes build/sig_evidence: run `sig_evidence.py -j 16` before `sig_evidence.py --check`.
- Arithmetic into a pointee offset that the pointee's type keeps in a gap/ext union (no typed leaf) is not a wall: it
  needs the pointee kind's variant field (trace the pointee's kind, C0630) before the member respell.
