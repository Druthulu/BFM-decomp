# Join C to binaries through build/ .d files and each binary's ELF symtab

- TU -> binary: build/src/*.d (main, top level) and build/src/<alias>/*.d (every other binary; twins have their own dir and list the primary's sources). Each .d lists every src/ and include/ file the object reads, so a header's lines belong to every object listing it.
- The .d paths are spelled `src/<B>/../shared/x.h`: normalize with os.path.normpath before keying, or one header counts as hundreds of files (3.44 T4.c1: 267k "files", 6,269 false orphans; normalized: 10,409 files, 0 orphans).
- Name -> address: `mipsel-linux-gnu-nm` on the binary's linked ELF (main build/us/SLUS_007.26.elf, else build/<B>/<B>.elf). It knows the auto-named func_ placeholders the config/symbols.*.txt files do not (C0571: names are per binary).
- A name defined under `__asm__("func_X")` is unknown to the symtab under its C name: count it apart.
- Implemented in tools/sig_evidence.py --compare (3.44 T4).
