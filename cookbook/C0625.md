# Absorbing many views into one parent in sequence: gap-union variants and the traps

Context: 3.45 T16.c5 (commits 5e7174360d setup, 4eff7d005c apply, 1381d314c3 stamp): 47 of 85 actor/player/sprite views
absorbed into the new parents through `restruct.py --fold-batch`.
- Declared gap unions: a parent field `union { u8 raw[n]; } extX;` is a variant region; ledger evidence `member:extX.<v>`
  (one token per gap the view touches; a gap without its own token takes the first token's variant) puts the view's fields
  inside [lo,hi) into variant `<v>` (padded, `unk<absolute offset>`), respelled `p->extX.<v>.unkNN`. A field straddling a
  gap edge, or an offset-class row with a field inside a gap, is refused.
- Rows applied in sequence must JOIN the sign unions earlier rows created (`union { u16 u; s16 s; } unk2;`): without the
  join every later row refuses. Copied bodies (one kind in several overlays) go on one batch line so two signs inside one
  variant open a sign union there.
- OFFSET_RX takes the FIRST `+0x..` in the evidence: absorb evidence must begin with `+0x0` (judge facts carry offsets).
- The walker misses `((T *)*(s32 *)(x + 0x64))->f`: scratch_cmp FAIL rows name them; hand-fold those sites.
- `--fold-batch --write` needs a clean src/include/config: commit the setup (parents, ledger rows, engine) first.
- Cost: about 30 min per --write of ~45 components on the full tree; scratch_cmp 4,284 objects.
- Refusal causes seen (no bytes moved, so pending, not walls): pointer parent field vs s32 view leaf (19/85), s32 position
  vs u16 reads of its integer half (11), multi-parent guard (4), include order of member types (2), gap straddle (1).
