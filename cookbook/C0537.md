# C0537 — struct_map size_hint can be an address: cap layouts at PSX RAM before rendering
tags: structs,census,restruct,oom,layout · date: 2026-11-06 · phase/task: 3.40/T17 · origin: P3.40 T17.c1 OOM

A struct_map record can carry an address where a size or offset belongs (size_hint 0x80180008 on Unkstruct_7148129c, 1 site). Any tool that renders or expands the layout flat (render_struct, t3_canon_twin's layout expansion) then allocates GBs; the dry run was OOM-killed at 30 GB.

- Before rendering, treat size_hint or any layout offset above 0x200000 (PSX main RAM) as a render refusal → residual TYPE-NO-LAYOUT `layout:refused(size>0x200000)` (restruct.py t3_residual, P3.40 T17.c1, 594da2e5e4).
- Symptom to recognise: a decide/write/audit run dies silently (kernel OOM, no traceback) on one record; bisect the record set and look at size_hint first.
