# C0533 — Census summary JSONs are capped; never rebuild rows from them
tags: census,json,structs,caps,trap · date: 2026-10-21 · phase/task: 3.40/T3 · origin: P3.40 T3 summary

Census summary JSONs are capped lists; never reconstruct full rows from them.

`type_census.json` caps dup classes at 300 (type_census.py:1497); a tool that rebuilt listed rows from it silently lost the rest (struct_twins.py, fixed 1ac31fbedd). Other caps: `residue_census.json` `top_types` 50; struct_map records `layout` 400, `conflicts` 50. Read the uncapped source (structs_stale, the generated doc, the full map) for row-level work; use the JSON only for totals.
