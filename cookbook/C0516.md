# Lying declarations: draw def + every caller; K&R-empty can be load-bearing (P3.39 T6)
- A lying decl is a per-callee unit: definition + all caller declarations (C0508), drawn with `restruct --rung D --callee F --signature '…' [--all-defs|--tu]`; `--plan --rung D` does not find them.
- Asm-label aliases (`aF<addr>`): K&R-empty decls in caller TUs keyed by the alias, not the real name; caller-only unit when the def is already spelled. Never respell `!FAKE` barrier declarations of an asm label.
- A def in a shared header is judged on every binary its includers build (one source can build two binaries); scoping by includer path fails as "conflicting types".
- Byte fact: when callers call with zero args and use the value, the prototype is a compile error; the K&R-empty decl stays, ledgered in config/lying_exceptions.tsv with cause ZERO-ARG-CALLERS (func_8012BD14, func_8012CBF4). PROTO-DIFFERS: the prototype changes a caller object (func_80014CF8, ov_MAIN_012 jr_801458E0.o).
