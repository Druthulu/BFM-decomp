# Proving a header change byte-neutral before the applier: overlay snapshot + cc1 asm diff over every TU

Context: P3.45 T17.c24/c24b judged 48 refused absorbs/folds read-only and proved each proposed header change.
- Build an overlay of a `git archive` snapshot, apply the header change and its respells there, compile all .c files with
  the project cc1 and diff the assembly against the unmodified snapshot (4121/4121 identical = byte-neutral; scripts
  .run/3.45/t17/c24/w/cc1all.sh, asmd*.sh). Add a layout assert and a negative control that fires.
- cc1 2.7.2 rejects anonymous unions (C0612): a union over a common field + a gap becomes a named member
  (`blkDC { s32 w[7]; struct { ... } f; }`), which costs respells of every use.
- Retyping a `void *`/s32 field to a typed pointer silently scales existing `idx*8 + p->unk90` byte-index sites: respell
  them in the SAME commit as the retype (alone, 2 TUs changed bytes).
- 8-byte struct value copies compile identically at alignment 1 and as SVECTOR: "alignment 1 vs 2" is not a refusal.
- Respelling a u16 view's reads onto an s16 field (SVECTOR) turns loads signed (25 TUs DIFF): fold into a u16 value type,
  never add per-read (u16) casts.
- A typed rebase of a +k window (`(Rec *)(base + 6)` -> `base->unk6`) moves the base into the load offsets: asm DIFF in
  every TU including the body (136/136): a wall class.
- Adding a pointer member to an existing fixed-point/link union (actor unkCC/unkD0 `void *p`) costs 0 respells and
  unblocks every view that typed that slot as a pointer.
