# Finishing a placeholder whose object is not a record: the `scalar` disposition (text|scalar)

Context: P3.45 T18.c22 (developer-approved 2026-11-20; Unkstruct_801407F4, 1,480 sites; 31378f18bf, 9282211c16, c01ea565d3).
- Use it ONLY when code reading shows the real object is not a record: text (e.g. NUL-terminated Shift-JIS strings of
  varying length returned from a text table) or plain scalar words. Never to finish a hard struct: a record whose
  parent is unclear goes up the tracing ladder (C0638, C0651, C0653) and to T30 with reasons, not to `scalar`.
- Prove it: read the pointees (c21 read 648 strings from the extracted overlays: lengths 0x20/0x22, NUL-terminated, returned
  as text next to other string returns). Different lengths or text returns rule out a fixed record.
- Apply: type the sources as the scalar they are (`u16 *` character slots indexed `[9..0xE]` instead of `view->unk12..`);
  retype globals typed to the view; delete the placeholder and its aliases; per-file cc1 asm identical; R22.
  Where a block-scope `extern u8 *g` elsewhere in the file blocks a file-scope retype, assign with one explicit `(u16 *)`.
- Row (tools/struct_twins.py rules): disposition `scalar`, class `text|scalar`; evidence `object:` + the data object's
  address or file:line (with a `(name)` note the cited line names) and `retyped:` + the retyped source file:line cites;
  reason starts `not-a-record:` with why; finished only with ` applied:<commit>` and the key no longer defined (the gate
  reports a broken row otherwise). Stamp after the apply commit (the stamp names its hash).
- Deleting lines from include/struct_types.h shifts survivor/wall evidence cites into it; no tool remaps them: shift them by
  the deleted count (.run/3.45/t18/c22/delete.py).
