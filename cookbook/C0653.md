# Judging ov_SC03 views: event records, spawn callbacks, raw kind dispatches, OT tag views

Context: P3.45 T18 wave A2 judges c1/c3 (ov_SC03, 126 overlays sharing bodies).

- Overlay header: +0x60 actor table, +0x64 fx table (C0629), +0xC8 a list of 0x24-byte event records whose handler
  pointers are called only from asm-only code: a view read by such a handler that is wider than the 0x24 record is not
  the record itself, and the C does not decide its object (refuse with that reason; judge with the event-descriptor family).
- Callbacks passed to `func_801788B8` run on the spawned child actor (kind 0x83), its parent at child+0x64 (C0640): a view
  inside such a callback is the child's variant, a view through +0x64 the parent kind's.
- T17's kind tracer (dispatch2 table) misses kind dispatches spelled `*(unsigned short *)(p + 2)`: grep that form when a
  handler has no kind edge (kind 197 in SC03_028 found this way).
- A view at `guess_g_OrderingTables.org` + 0x40 is OT tag 16 of the u32 tag array: not a struct object.
- Shared-body types (~130 sources, one per overlay copy) are judged once on one copy; say so in the row.
- The 0x2C views with `+0x15 u8` / `+0x28 s32` are the event runner at 0x800AE6A8 (ledger root `Dst`): an event record's
  +0x4 word is the script function, loaded into runner+0xC (src/resident/resident_jr_800D128C.c:536-539) and called with
  a0 = runner (:789-794). P18, Struct800D2FEC, Unkstruct_801596F0/80159698/8017D8A4_2 view the same global (judge c2).
- Alias typedefs (`typedef X Y;`) move with their target: retype the alias's sites in the same batch.
- A variant named from writes through a pointer field must check what that field holds for the kind: kind 418's actor
  +0xD4 holds a sprite record (ov_SC03_096_jr_8017BEBC.c:4069,4415-4428), so writes through it are sprite fields, not
  actor extA (judge c4; T17's extA kSC03_093..097 variants were made this way).
- More kind-tracer misses (judge c5): functions in actor +0xBC id tables run through func_80131CA8.h:9 `fp(a0)`; functions
  called by sequence op 0x33; states dispatched through shared cls_*.h headers. Search these before refusing a kind.
- Value shapes with no PsyQ fit keep one shared value type per shape (contract 2): it is a survivor when a real struct
  member or declared object (global, static, local) has that type; twins of the shape fold onto it. A shape seen only as
  a cast over other objects' bytes is no survivor.
- A view whose object is a Shift-JIS string buffer is no struct (refuse: char data), e.g. func_801407F4 (judge c6b).
- Script-word functions (called by the actor script interpreter) get NONE from T17's c28/w/kind.py; trace them up the
  table chain to the owning kind with T18.c7's kind2.sh (.run/3.45/t18/bin/kind2.sh; method in its header).
- Apart rows from T2 (`apart own C<n>`) are not binding for a view: common-field views of the actor absorb (judge c7).
- Second-pass tracer misses (judge c12): where.py skips dispatchers whose definitions are indented; small-object spawns
  spelled `func_80146AB4(kind, ...)` are invisible to `guess_SpawnSmallObject` greps; module slot words (0x800CB190) are
  shared by several md_* modules, so an overlay table word does not name the module.
- Dead copies of a live body (no table or caller reference in that overlay) take the live copy's parent: same text, same object.
