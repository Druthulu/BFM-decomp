# sys.exit in a multiprocessing.Pool worker hangs Pool.map

- `sys.exit()` inside a worker raises SystemExit, which kills the worker process; `Pool.map` then waits forever for a result that never comes (3.42 T8.c1: tools/leverage_rank.py hung 13 min, killed by pid).
- Fix: a worker raises an ordinary exception (RuntimeError with the message); Pool.map re-raises it in the parent, and the parent exits non-zero.
- Rule of thumb: only the parent process calls sys.exit; workers return or raise.
