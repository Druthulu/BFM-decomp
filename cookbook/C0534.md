# Dead constant-address temp folded into its derived pointer: compute the pointer in the loop-test block

Symptom: `it = (s32)&A; p = it + K;` with `it` dead before the first use -> cse folds to `la a0,A+K`
(extra nop/insn vs target, which keeps `it` in a reg and adds K).

Move: move `p = it + K` into the `test:` / loop-condition block reached by `goto`. `it` becomes live
across the jump, stays in its reg, and `p` is computed from it in the `j` delay slot. Took
func_8012C2D0 from 4 to 1 lever-free (launder removed).

Wall left: once `p` is born in the test block it carries no REG_EQUAL, so cse1 canonicalises
`(eq it,p)` to `(eq p,it)` -> `beq` operand order flipped (score 1). Flipping the C comparison,
subtracting, or swapping decls does not move it. Wall tag `cse-const-addr`.

Evidence: .rtl ne(it,p) -> .jump inverts to eq(it,p) -> .cse1 eq(p,it). Source: T11.cG16 (P40), DeepSeek coder.
