# C0587 — A body whose exits only pass entry $v0 through has no return to contradict void

# A body that never writes $v0 has no return, whatever its callers read

- An h_exact class merges unrelated functions with equal bytes. The empty body `jr $ra; nop` (func_80014554, 726 addresses, R123) is one class. A caller anywhere that reads $v0 after a call to one of them (or a tail-use chain through one) makes the class `used`.
- Every exit writer of $v0 in such a body is `entry` (the value passes through from before the call). It is not the function's return, so a `void` definition does not contradict it.
- Rule: a return-use contradiction (a read against `void`) needs a class with at least one exit writer that is not `entry`. 3.44 T4: without this, one class made 106,201 of 215,375 RET-VOID-READ rows.
