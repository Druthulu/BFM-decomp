# Fold engine after T7.c15: what it follows, --fold-collapse, and the forms still by hand

- Walker (restruct.py, 0bb6e2e5ee/f703dc69d5, selftest 177): follows accesses through fields of records typed with the
  member (3 levels, nested anonymous structs/unions), objects declared with a definition, macro-aliased globals, cast and
  bare macro-parameter bases (bare: typed at every expansion, refused with a cite when expansions disagree), and shared
  bodies (src/shared/ov/*.h) through their includers' declarations when all agree. c14's "136 FAIL new" were these misses,
  not jump-table drift: scratch_cmp now prints the first compiler error of a FAIL row.
- Merge: one variant per type (short≡s16, alias spellings), padding subsets join a variant, array over scalars keeps the
  target's spelling (constant index respelled `h[5]`→`y.vy`; variable index refused with cites). `--fold-collapse
  [TYPE…] [--write]` re-plans committed variant unions by the same rules (57 → 37 variant structs, 7,173 edits).
- Still by hand: an aggregate initializer of an array member mapped onto scalar fields (`{{0xFF,0x80,0,0}}` changed one
  .rodata byte: drop the inner braces); definitions that also declare objects; bit-field targets.
- Census trap: folding out the last member whose field names are meaningful leaves the remaining opaque names as a
  tier-1 duplicate class that gates; fold the rest too or list the class in docs/struct-twins.md with an address cause.
