# Judging A5 placeholders (no census cast source): deref-operand views, spawn-record folds, stack records

Context: 3.45 T21 wave A5, the types T16's projection listed with no cast source. Judge c4 (ov_SC03/SC02 list, 87 types).

- "No cast source" was a T16 snapshot. After A1-A4 respelled their holders, many such types are read at HEAD as
  `((T *)*(s32 *)(a0 + K))->f` (deref-operand casts the census undercounts, C0644). Grep the type name, read K:
  K=0x20 is the actor render pointer (RenderHead, or the model record when an access passes 0x30, e.g. +0x80);
  K=0x64 the spawner actor's common fields (a variant read when the offset sits in a gap; C0640); K=0xCC/0xD0 per-kind
  held sprites or a found actor (func_8012E57C(kind, key)); +0x68 the spawn record S8012C658; +0x78 a per-kind static
  descriptor (survivor static, cite valid only after the descriptor global is retyped, C0652).
- Stack records passed to a typed callee fold link onto the callee's parameter type (spawn requests to func_8012C51C fold
  onto S8012C658). Stack records with no typed callee (scratch, frame layouts) are flagged for the expert: no
  survivor class names a stack object.
- Packet descriptors fold onto the existing draw-descriptor types (Src_80016C28, Src_80017930, POLY_FT4); a T2
  "conflict" with the next packet in the buffer is adjacency, not the same object.
- Check value folds against the data: a 4-byte "position" view was grey rgb 0x00C0C0C0 -> CVECTOR.
- A list's ledger file_line cites go stale as the header shrinks: locate definitions by `} Name;` grep.
Files: .run/3.45/t21/c4/notes.md, judgments.tsv; scripts .run/3.45/t21/c4/w/ (uses.sh, def.py, ctx.sh, check.py).

Judge c3 (ov_SC02/SC01/ov_MAIN list) adds:
- Frame-layout structs: a stack struct that only fixes the frame order of several locals (MATRIX + a draw request,
  MATRIX + 2 SVECTOR, three RotTransPers outputs) is no object; no PsyQ type covers it. Judges refuse it with the
  frame shape; the finish is the expert's (split into typed locals under the byte gate, else a wall with both attempts).
- Stack draw-request blocks fold onto main's draw-routine request types (Src_80016A7C, S16F18, Src_800173DC,
  Src_80017B98) once those are finished as survivors like Src_80016C28.
- Parallel globals, split dlabels, frame pads and bitfield sign-extends are codegen levers spelled as types: a respell
  must pass the byte gate before it is a finish.

Judge c2 (md/main/ov_MAIN list) adds:
- Mis-based views in main: a table seen 4 bytes low or high (Slot16A/Rsc16 over Slot16 D_80076244[5]; Ent24 over Rsc24)
  is the same object; keep the type that carries the fields as the root, absorb the others at +/-4.
- A fold whose target is itself an applied fold row's source must be re-pointed to the chain's end (Poly_8016CBC0 ->
  Prim_md_MAIN_047_800CCBC0 -> Src_80016C28).
- Stack MATRIX buffers with frame padding or aligned(8)/packed attributes are likely byte refusals when folded onto plain
  MATRIX: expect the second attempt (or a wall) there.
- Code-pointer tables, SJIS strings and name text are scalar finishes (C0656).
- The inventory's h_exact column is not a layout hash; get lhash from struct_twins.py --show or struct_layout.

Judge c1 (main + families) and the expert's stack-record decision:
- One record on the stack used as itself (a draw request built by callers and handed to a main routine, a local record) is
  a survivor class alloc (a stack allocation every use of which is the type), cited by declaration function:line and
  callee; a stack record that is a callee's parameter type folds link onto it; several unrelated locals in one struct
  (frame-layout) are split into typed locals.
- Resident dispatchers reached only from descriptor tables (asm/resident/data/tail.data.s) hide their record: trace the
  code that calls a descriptor's function with its record before judging arg0.
- New PsyQ values need survivor sdk rows (C0669): LINE_F2, GsCOORDINATE2, GsIMAGE (GsGetTimInfo fills it).
- MATRIX_L48 is a type_census control: a fold that splits its uses (CdReq req -> 80034DFC; camera -> MATRIX) re-points
  the control in the same commit with the reason.
- An applied fold onto a type now folding elsewhere (VoiceF80 -> Voice336A8) is redirected to the new target.

Judge c5 (SC03/04/05/06 list): survivor cites on globals declared as u8[]/other types only become valid (C0652) once the
global's extern is retyped to the survivor type: the applier retypes the extern (byte gate) in the same batch. A record a
sprite head +0x20 points at (D_8018DE74, 12 bytes) has no type yet: one extern stays the refusal until that record is judged.

Judge c6 (shared bodies, SC06/SC07): views cast from a main global (`(P18 *)D_800AE6A8`) are that global's root (Dst, the
event runner), and the resident +0x15-state dispatchers read the same record; folds onto a type that turns out to be a
view (S800D1938 -> P18) are re-pointed to the root. The player's record fields may be member survivors (Packed8 at
player +0x140 = D_80126C98). Functions compiled at -O0 (func_80144B9C) keep their bases as struct pointers: respelling
must not drop the base variable.

Applier c8 (survivor/scalar batch, 78 of 83): scalar finishes can refuse on bytes where a struct spelling is a codegen
lever: at -O0 (md_MAIN_011) a one-member `.fn` struct folds the symbol into `lw $r,D_x($i)` where a function-pointer
array gives `la; addu; lw`; a 1-byte struct passed by value stores with `sb` where u8 gives `sw`; a struct extern keeps
the symbol address in a register (`la`); 3- and 10-byte struct copies (copy units) change register allocation when
respelled byte-wise. Those go up the ladder for a second attempt, then become walls (class retype, residual
ADDRESS-FOLD/WIDTH/REGALLOC). Survivor cites: start the evidence with the definition line; keep only cites whose line
names the type (struct_twins cite_holds); deleting definition lines shifts other survivors' cites in the same header.
