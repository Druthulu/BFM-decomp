# Second attempts on held actor keys: split a gap at top level, read the pointer leaf, census name collisions

Context: P3.45 T17.c35, the second attempt on 11 actor keys c32 held (8 moved, 3 held, 0 walls).

- A gap variant with an s32 cannot fit a 0xA gap: any aggregate holding an s32 pads to 0xC; s16 halves turn `sw` into
  `sh`. When the gap has no other users, split it at top level instead (extB raw[4] @0xA0, extB4 `{s32 unkA4}` @0xA4,
  extB8 `{s16 unkA8}` @0xA8, unkAA unchanged): asm identical.
- struct_twins' field-read pattern (tools/struct_twins.py:2692) counts an assignment as a field read only for `->f` or
  `->f.p|.m|.s`; a `.val` (or nested `blkDC.f.unkDC.val`) read is "other", so the local keeps only its arithmetic
  definition and becomes untypeable. Read the pointer leaf (`v1 = (s32)E->unkD0.p`) to keep it typeable (set of
  untypeable sites unchanged, 32432).
- The census keys locals by name per function: a block-scoped local that shares a name with another is merged with it,
  so a local can count as typeable only through the collision. Typing its own source then turns an I cast into a C cast
  (casts_C rises): hold the key, cite the collision.
