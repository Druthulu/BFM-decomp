# Key SHARED_FN cross-header bodies by their header, cited by an includer's address

**Wall (3.45 T6.c2/c3).** Cross headers (`src/shared/ov/*.h`, included per site with `#define SHARED_FN func_X`) spell
their function as the macro name. struct_twins keyed parameter, return and same-routine objects as
`shared/ov/SHARED_FN:<param>`. As a result, every cross header shared one object. That false object joined 14 twin
classes as SHARED. `--write` then dropped their `## Twins` sections, and type_census `--check` failed with dup_classes=14.

**Fix (struct_twins `scan_file`, `scan_all` pre-pass `shared_includers`).**
- Key a SHARED_FN routine by its header file. Copies with the same body text still join through the body-hash key, which
  is a real object.
- Cite the header by the lowest address among the functions that define SHARED_FN and include it. Without an address,
  type_census rejects the twins cause (type_census.py:1180) and the class counts as stale.

**Check.** Run with the fix turned off and on, on the same tree. The only difference is the restored sections.
