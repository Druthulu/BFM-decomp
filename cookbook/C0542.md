# Name a lever's wall mechanically: first RTL pass where pinned and lever-free compiles diverge

- Compile the body twice (lever kept / lever removed) with cc1 2.7.2 `-da`; renumber pseudos, map the pinned var to its pseudo, compare each dump in pass order up to sched1 output.
- The first differing pass gives the tag family (cse, loop, combine, sched1, expand); the sub-tag from the var's set source / the diff content.
- Identical through sched1 → allocator: local-alloc pseudo: copy/dying tie → lreg-copy-pref, hard-reg conflict → lreg-hardreg-conflict, else lreg-priority; global-alloc pseudo: a local qty holding the target reg → lreg-priority, else greg-copy-pref vs greg-priority by preference.
- T20.c1: 26/26 hand-read probes agree; ran on 250 scratch-pin rows (script `.run/P40/t20/bin/predictor.py`, scratch). Sub-tag rules are heuristics; the family is the solid part.
- Traps: scratch TU copies lose TU-local `#include "x.h"` (empty dumps): rewrite to absolute paths. Do not classify pins by grepping var names: `// !FAKE: pin $4 tag0 …` comments match. An asm symptom in a sched slot can start at expand: name the pass where the dumps first diverge, not where the asm differs.
