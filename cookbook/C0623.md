# C0623 — Typing engine (rung T) batches: type untyped callee slots first; --only by binary; ratchet after
tags: restruct,rung-T,typing,param,ratchet,struct · date: 2026-11-15 · phase/task: 3.45/T15 · origin: P3.45 T15.c3 pilot

- Tool: `restruct.py --type-source KEY | --type-batch FILE [--write]`, `--type-check --only <binary|region>` (rung T, docs/ops/p345-t15-typing-engine.md).
- Order: on the md_SC02_009 pilot 17 of 34 pendings were `non-cast arg-int`: the source is passed to a callee whose slot is an integer (guess_StartActorSequence#0, func_801E53E0#0, guess_InitActorModel#0). Type the callee's parameter first (rung T param on the callee, its definition and declarations as one unit), then re-run the callers' keys; one callee retype unblocks every caller passing that object.
- A batch on one TU: keys apply in order on the tree the previous key left; the write guard accepts files the same run wrote (`t_dirty`), else every key after the first is refused.
- `--only` takes a binary (md_SC02_009) or a T14 region (`md_*`, `ov_SC03`, `shared`).
- After `make clean`, run `sig_evidence.py -j 16` before `struct_twins --sources` (it reads build/sig_evidence/census.jsonl).
- A typing batch lowers casts_C etc.: the gate then fails "ratchet stale" until `struct_twins.py --gate --write-ratchet`, committed with the batch (C0621).
