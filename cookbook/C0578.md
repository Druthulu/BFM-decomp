# Keep a residue row's wall beside its lever: ` wall:<tag>` in the `// !FAKE:` marker, gated

Problem: a lever's wall lived only in config/lever_residue.tsv; a reader of the source saw the instrument, not why the lever stays.

Move (3.43 T12.c1):
- Append the row's ` wall:<tag>` at the end of each excused site's `// !FAKE:` marker (site line, else the line above); keep the
  instrument text so INSTRUMENT_FORMS attribution still matches.
- `lever_census.py --check --strict --residue` runs `wall_comment_check`: per marker line, the found tags must equal the set
  required by its excused sites' rows. Fails: no-marker, no-wall, wrong-wall, stale (a tag on a non-excused site's marker).
  It prints the expected tag per failing site, so a re-tag or a removed row is fixed by editing the comment.
- Written once by a scratch codemod (.run/3.43/t12/wall_comments.py) over the census's own sites; idempotent.

Trap: a marker for an asm `#define` must not go on the `#define` line: the comment joins the macro body and changes its
text_hash. Put it on the line directly above (e.g. the `#ifndef` guard); walk_file's orphan rule accepts that position.

Counts at landing: 1,850 sites, 1,846 marker lines (4 shared by two sites with one tag), 0 multi-tag lines.
