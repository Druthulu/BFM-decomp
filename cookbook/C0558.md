# One-text sharing of differing copies (D/B cross classes): what the byte gate cannot see

- Use: `share_body.py --bucket cross` on verdict D (differing texts) and B (partly registered) cross-address classes (3.42 T6).
- Rule: rank distinct texts by raw casts + `// !FAKE:` markers, then lowest address; on a reject retry the next text in the same run; the header's provenance comment records rank k/n, counts and each earlier rejecter.
- Trap: `gated N/N` is not enough. One text can leave a struct with no user (`type_census dead`) or turn a private `s32` copy into the shared `void` text (unledgered lying). Run type_census --check per batch and treat a dead type or a new lie as a reject of that text.
- Trap: count raw casts with type_census's four forms (P, I, X, M); a typed member access `((T *)e)->f` is not raw. A home-grown cast regex picked cast-form texts and killed the struct users.
- Trap: typedefs live in include/*.h AND src/shared/engine_types.h.
- Trap: an alias-form copy can carry another address's alias (ov_SC03_001 defines aF801848DC bound to func_8018739C); take the own name from the def head. share_census.py:236 records `#define SHARED_FN aF…` without its alias map, so the sites become UNACCOUNTED.
- Trap: share_census defaults to `--scope same-vram`, where cross violations read 0; measure with `--scope all`.
- Trap: cen dirs["main"] is `src`, so a prefix test matches every TU; bisect restore must special-case main.
- Trap: the restruct ledger is append-only and untracked; a tree reset keeps rekey rows, so skip a header only when the stored nhash still matches.
- B merge: drop old E_ groups and delete orphan headers only after the class is green (unlink, then commit_task.sh's `git add` stages the deletion; `git rm` makes commit_task refuse the path).
- Trap (T6.c2): one text can change a copy's return type. An empty `s32 f(void){}` has the same bytes as `void f(void){}`, so callers' `extern s32` become return lies, which only type_census --check sees (class 7678540574: rank 1 lies, rank 2 conflicting types).
- Fact (T6.c2): argcheck already binds `#define SHARED_FN X` + include as X's def with the header's prototype; a lie after a share comes from the text, not argcheck.
- Dead-type repair: delete the dead definition in the same batch only when it has one whole-line definition and nothing references it (src/, include/, docs/struct-twins.md, tools/type_census.py); a twin-listed type is refused. share_body exits 0 on rejected classes: read batch_<label>.json.
- Trap (T6.c3): a type-header edit (dead-type deletion in include/) belongs to every binary's bisect set, or undoing it while bisecting another binary leaves that binary red. Cost: a deletion class re-gates every binary (cross21 took 3.2 h).
- Trap (T6.c3): a batch tool that commits a fixed list of dirs misses a dir it newly edits; its dirty-tree check must cover the same list (include/ deletions sat uncommitted cross21-24).
- Trap (T6.c3): copy names come in three forms (sig name, `aF<ADDR>`, `<name>(...) __asm__("func_<ADDR>")`). Every name-keyed record (restruct rows, registry member names, lying ledger def_file) must match the form written, or progress.py, check-casts and type_census drift while the byte gate stays green.
- Fact (T6.c3): type_census keys an include-site def by the site's source file, not the header; never re-key lying-ledger rows to the header.
- Trap (T6.c3): the in-batch type check runs before the ledger re-key; only tools-health after the sweep catches re-key bugs.
- Skip rule (T6.c3): one red batch puts a class on the skip list (`batch_t6probe*.json`, `batch_cross<k>.json` rejected/refused); some rejects are collateral (an error in another class's header, a warning-only cause line), so a remainder is an upper bound.
