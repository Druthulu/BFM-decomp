- A first naming of a splat auto-name is an added line only; `--range` maps it to old = func_/D_<ADDR> (`// data` -> D_).
- Classes: history (closed path list incl. .run/) / rewritten (line carries the new name) / stale-build-input / stale-invisible / unclassified (bare or 0x address, no new name). Any stale or unclassified exits 1.
- decomp-architect/corpus/ copies of tools are stale until `make kit-corpus`; run it, then re-scan.
