# C0544 — Lever residue rows key (file, func, kind): one crack re-causes a row, an unused row fails strict
tags: levers,residue,walls,strict,gate · date: 2026-11-07 · phase/task: 3.40/T13 · origin: P3.40 T19/T20/T13

How `config/lever_residue.tsv` rows key the strict lever gate (3.40 T19/T20).

- A row is keyed by (file, func, kind) and excuses every site of that kind in the body. Cracking one pin of several leaves the row in force: re-cause it (and re-wall it) for the pins that remain, never delete it.
- A row that excuses nothing is `residue-unused` and fails strict. After a crack that removes a body's last site of a kind, drop the row in the same commit.
- Each row's cause must end ` wall:<tag>`, with the tag a row of `config/lever_walls.tsv` (`--walls` defaults to it). `--write-residue` writes new rows unwalled on purpose.
- The milestone form is `lever_census --check --strict --residue config/lever_residue.tsv` (OK, residue-unused 0, unwalled 0, unknown-tag 0) plus `--check` (0 UNMARKED). Bare `--strict` is not a gate.
