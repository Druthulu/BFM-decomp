# Run a repo-wide check on unedited HEAD before blaming (or crediting) your edit

A done-when like "docs link check passes" or "tools-health OK" is a whole-repo check; it can be red for reasons
outside the task (P38 T8: `tools/doc_links.py` was red on two UNCOVERED docs added by the structs tasks, not by the
formats.md edit under test).

- Before editing, run the check on unedited HEAD and keep its output: that separates pre-existing failures from yours.
- A pre-existing red is either fixed in the task (smallest change, listed as a deviation outside `files:`) or
  reported as such; never leave the done-when red and never call it green.
- Mirrors are the common source: any tool or doc copied into `decomp-architect/corpus` makes `make tools-health`
  red (`tool_census --check` gaps) until `make kit-corpus` is run; run it in the same task that edits the
  original (P38 T10).
