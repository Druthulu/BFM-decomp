# Joining a leverage unit to its dedup group and sig instances

- leverage key = h_exact[:12]. `.run/P35/census/classes.jsonl` holds only classes with >= 2 instances: a fan-1 unit's full h comes from the `.run/sig.<alias>.jsonl` row whose h_exact starts with the key.
- config/dedup.us.yaml has two group forms: `members: [{binary, vram, name}]` and `vram:` + `binaries: [...]` + `func:` (members = (b, vram) for each b). 3.43 T1: 2,990 of 6,275 groups use the second form.
- tools/rename_sym.py load_groups (:180-183) reads `members` only, so `class:<id>` on a vram+binaries group expands to no rows (no error). Of the 196 grouped worklist funcs, 188 hit this.
- One h can map to many groups (rank 1, func_80014554: 132 groups, 177 aliases), and a group can miss sig instances (9 worklist units, mostly md_*, resident and ov_SC07_*). Compare the union of groups with the sig instances before you trust a class target.
- Sig alias set: share_census.fleet_and_dirs(), the same set leverage_rank uses; the sig instance count equals leverage `fan` for functions.
