# Third pass on unresolved pointer sources: retail-asm callers, dispatch tables, all-predecessor register traces

Context: P3.45 T17.c25/c25b re-judged 466 sources two classifier passes left (257 decided, 213 residual with reasons).
- Callers in co-resident binaries: an md module is co-resident only with the overlays whose data reference it; paths
  through an md no overlay references are flagged md-host-unknown, not trusted blind.
- Overlay header tables f5C/f60/f64 also hold md handler words; script tables run by func_80178CBC/func_80178B18 and jalr
  tables give indirect callers. Global initial words + every store give a pointer global's object.
- Function starts: a prologue right after `jr ra` + delay slot is a start (dispatch-only functions are otherwise missed).
- Backward register trace ($a0 provenance) must follow every predecessor (branches, fall-through, jump-table jr): a
  linear walk gave false "clobbered" verdicts and missed jalr tables. Pointer + constant in a loop keeps the object; a
  NULL-only path yields; disagreeing paths each labelled, decide only when all agree.
- An "effective type" recorded at a source's own call sites is circular evidence: check the consumer's declaration
  exists (8 consumers were asm-only).
- Dead functions (no jal, data word or address formation in any co-resident binary): decide only by consumer evidence
  (a helper with 10+ decided callers all of one parent); otherwise residual "dead, no flow".
- "Not-pool" sources: pointer globals to the scratchpad (0x1F800010, SVECTOR), static record tables: name the real
  object, never the actor/sprite pools.
