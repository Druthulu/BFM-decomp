# Per-source absorb: split one placeholder across several parents by its pointer sources

Context: 3.45 T16.c7 (1df67e0abc engine, 03e446178d apply 568 files, 97e95b3b0c stamps). A placeholder whose sources reach
different objects (Unkstruct_800B5CB8: actor slot, sprite record, model record) cannot be absorbed whole.
- `restruct.py --fold-batch` line `VIEW<TAB>PARENT<TAB>EVIDENCE<TAB>*|KEYSFILE`: `*` = the type-level absorb with the
  multi-parent guard waived; a keys file = T14 source keys (optional `member:extX.v`, `lines=A-B`) whose casts
  `((V *)X)->f` respell to the parent's field path, bare `(V *)X` rename, typed copies `V *x = (V *)…` retype with their
  `x->f`. Only the moved sources' fields merge; V's definition and other uses stay; the parent never grows.
- Indexed, arithmetic or dereferenced-cast sources are "unsafe" and not moved; the batch writes `<batch>.srcs.tsv`
  (moved / unsafe / unmatched per source).
- TRAP (C0626, reverse): a view's s32 leafmapped onto a parent TYPED pointer (unk64, unkD4) changes bytes wherever code
  does `->unk64 + k` (offset scales). Screen sources for arithmetic on such fields before moving them.
- Classify a merged type's sources by the pool each reaches (C0624); sources reading only offsets common to two pools
  (< 0x38 for actor/sprite) stay ambiguous until a flow decides (800B5CB8 slice: 163 -> actor 80, sprite 14, model 4, stay 65).
- Cost: each actor-parent component about 77 min (the target walk over every file naming the parent): put all groups for
  one parent on ONE batch line.
