# C0529 — git clean -X with a pathspec inside an untracked ignored dir deletes the whole dir
tags: git,cleanup,trap · date: 2026-10-19 · phase/task: 3.40/partner · origin: .run cleanup 2026-10-19

Trap: `git clean -fdX -- <path/inside/dir>` removes the WHOLE enclosing directory when that directory is ignored and holds no tracked files; git reports the dir itself as one ignored entry, so the pathspec does not narrow it.
Seen 2026-10-19 (.run/ cleanup): `-- .run/keep/p37-ledger.jsonl` deleted all of `.run/keep/`; `-- .run/P36/regen/<sub>` deleted all of `.run/P36/regen/`.
Safe use: only pass paths whose parent dir holds tracked files, or dry-run (`git clean -ndX -- <paths>`) and read every "Would remove" line before running. To delete one ignored file, use `rm` on that file.
