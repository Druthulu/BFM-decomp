# Counting a call's outgoing stack arguments from asm: which $sp+16.. stores are arguments

- A store to the caller's $sp+16+4k before a `jal` is argument 4+k only if it is not frame traffic. The same slots hold register saves (`sw $ra,0x10($sp)` in small frames) and locals, which inflated site arity to 13-44 in 3.44 T3.c1's first run.
- Rule that held fleet-wide (tools/sig_evidence.py, rule ARG-SITE in docs/ops/sig-evidence.md): count the slot only if the function never loads it back, it lies below the lowest local whose address is taken (`addiu rX,$sp,off`), and it continues a contiguous run from $sp+16. Result: site max <= 13, only 14 classes above 9.
- Extends C0238 (sw at 0x10/0x14/0x18 are params 5/6/7) with the exclusions that make it safe at fleet scale.
