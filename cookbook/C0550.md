# New tool files: git add -N before make kit-corpus
tool_census (run by `make kit-corpus` / tools-health) compares `find tools/` against `git ls-files`; a new, uncommitted tool file reads as untracked drift and fails.
Move: `git add -N <new files>` (intent-to-add) before `make kit-corpus`, then commit through commit_task.sh as usual.
Source: P3.41 T7.c1 (tools/ghidra_types.py).
