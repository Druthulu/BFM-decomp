# Placeholder names are per binary: a repo-wide token rewrite renames unrelated functions

**Trap.** `func_<ADDR>` / `D_<ADDR>` placeholders are derived from the address, so the same token names DIFFERENT
functions in binaries that share a vram space (the location-overlay slot 0x80128158, md modules). tools/rename_sym.py
rewrites `\bold\b` over every tracked file, not per binary. Safe only when every file holding the token belongs to a
binary the spec row covers (or the token there means the same function).

**Seen (3.43 T7.c1).** func_80146CA0's 14-address class: the non-base copies' old names (func_80184B00, func_8018354C,
func_80185458, func_801854F4, func_80186B70) are also unrelated functions in other overlays (e.g. ov_SC03_024 would
get guess_NextStep_2 twice). Separately, md_* modules call 141-overlay class functions as externs resolved by splat's
build/md_*/undefined_funcs_auto.txt; md symbol stacks (us + own) lack the new name, so a rewritten md call needs a
plain md-alias spec row (same runtime function) or it is left stale.

**Check before a batch.** For every old token, list the files holding it (GNU grep -F -f over git ls-files, C0570),
map each file to its binary (src/<binary>/, shared headers via their members), and flag any binary not covered by the
spec row: .run/3.43/t7/hazard.py does this. A 141-base class token is safe; extra copies at non-base addresses and
singletons in one overlay are the risk. Fix: drop the unit until rename_sym rewrites per binary, or add the binaries.

**Cost.** A dry run with ~1,000 expanded (old,new) patterns over every file took > 59 min (c1); rows of one class
repeat the same pattern 141 times.

**Fixed (3.43 T9.c1, 53b4b0e9e8).** rename_sym now scopes each (old,new) to the binaries stacking the row's symbol
file: a mapped file (src/<b>/, shared header members, config/symbols.<alias>.txt) is rewritten only when all its
binaries are in scope, `skipped:` when none are, `error:` (exit 1, nothing written) when it straddles. Unmapped files
(config/dedup.us.yaml, docs/, tools/) are rewritten only for unambiguous olds, else printed `unscoped:` and edited by
hand (dedup.us.yaml member names: only that class's members). rename_scan --spec classifies a stale hit in an
out-of-scope binary as `other-binary` (not bad). md modules calling a 141-class function are skipped unless the spec
carries md-alias rows. hazard.py is no longer needed for scoping.

**Follow-ups (3.43 T9.c2-c6).** A resident caller of an overlay function gets no alias row (every overlay stacks
symbols.resident.txt -> splat "Duplicate symbol", 153 extracts failed); bind its extern with `__asm__("func_<ADDR>")`
so lint_symbol_refs passes. md-alias scans must include src/shared/slot_*. A generated doc quoting another binary's
kept placeholder as an object id (`src/resident/0x800D21C4:func_801465C0`) scans `other-binary` (rename_scan
_qualified_out, 965c6193c0). A cited library-symbol citation (`build/us/SLUS_007.26.map:<line>`) drifts when names
change: recheck every map citation after the batch's clean build (tools/map_cite_check.py [--fix]).
lint_symbol_refs is binary-scoped too (4a102028a3): a src file is checked only against its binaries' symbol stacks;
before that, naming non-base copies (rank 3's 14 addresses) gave 298 false stale refs. Tool selftest fixtures must
use addresses outside RAM (0x80FFFFF0): rename_sym rewrites tools/ for unambiguous olds, so a real-address fixture
gets renamed (548b82143d).
Unmapped name-keyed files hold same-address tokens of OTHER entities; rename_scan --spec (scoped rows) classifies
them other-binary from line facts only (11ff06f7d9 rules: D_ token for a func rename and vice versa; dedup member
`binary:` out of scope; lever_residue src path out of scope; leverage.tsv row of another hash; T9.c10: type_folds
owner whose target type is used only by out-of-scope src). Non-base copies of a multi-address class need these.

Count instances from sig rows, not dossiers (3.43 T10.c1): a tiny wrapper class can carry md_MAIN private copies at
many addresses (R245: one 141-binary class + 27 md copies in 22 modules, two in some modules). List them from the
.run/sig.<alias>.jsonl rows with the unit's h_exact (.run/3.43/t10/sigaddrs.py); T6's dossier missed md_MAIN_028's
indented definition. Every copy needs a row (`_2`.. in address order) or the shared-header rewrite straddles.
