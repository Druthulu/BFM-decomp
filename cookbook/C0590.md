# .d dependency paths need normpath before matching edited files

- `build/src/**/*.d` spell shared headers as `src/<binary>/../shared/...`; matching edited paths raw against them misses
  every TU that includes the header (3.44 T5.c4b: 10 objects found instead of 151).
- Fix: `os.path.normpath` each dep before comparing with the edited-file set (repo-relative both sides).
- Symptom is silent: a scratch compile "all identical" over too few objects. Sanity-check the object count against
  `grep -l <header> build/src -r --include=*.d` after normalizing.
- Related: C0589 (scratch-compile recipe).
