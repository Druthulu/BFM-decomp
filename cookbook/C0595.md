# Return-less defs at scale: driver loop, census join traps, the if/else return shape

- Loop (3.44 T7.c1, 690 defs, 0 comments needed): load RET-NONE rows + census class -> candidate per site -> apply from HEAD text
  -> scratch-compile every object whose .d lists an edited file (C0589/C0590) -> judge per function symbol -> losers get
  the C0567 `$v0 at exit:` comment -> recompile. Scripts: .run/3.44/t7/{load,cand,drive}.py, compile.sh (scratch).
- Tail call through a cast view (`((void (*)(...))f)(...)`): change only the view's return type to f's definition type
  and `return` it; the callee is never retyped. 405 of 690 sites.
- `if (c) f(); else g();` as the tail: a `return` in each branch reorders the branches (`bne` moved). One local
  `r = f()` / `r = g()` plus a single `} return r;` is neutral.
- Census joins: symtab names are lowercase (`func_8012b864`): normalize before matching C names. Callees defined only via
  `T CNAME(...) __asm__("NAME")` need the alias line grepped for their definition (C0223). A shared class's exit cite
  names its exemplar binary: resolve `call 0x..` there, not in the instance's binary.
- A local introduced to hold a call result turns a cast on the call (no site) into a raw P/I/X/M site on the
  local (`s32 r = f(); *(s16 *)r = …`): tools-health `--check-casts --residue` fails `uncovered I=1`. Type the local
  instead (`s16 *r = (s16 *)f(); *r = …; return (s32)r;`, byte-identical; T7.c4).
- Read HEAD text as bytes: subprocess `text=True` silently turns CRLF into LF.
- Related: C0567 (ladder), C0589 (scratch compile), C0547.
