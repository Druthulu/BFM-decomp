# tool_dictionary.tsv phase column takes roadmap ids, not phase numbers

- `config/tool_dictionary.tsv` column `phase` accepts only P1..P10 (the kit roadmap phases) or PROJECT-ONLY (tool_census rule R43).
- A row with `P3.44` makes `make kit-corpus` exit 2: "bad row for tools/<x>: phase=P3.44".
- Pick the roadmap phase that fits; Gen 3 signature/readability tools use P10 (sig_evidence.py, scratch_cmp.py).
- Related: C0550 (`git add -N` before kit-corpus), C0553 (no project tokens in dictionary prose).
