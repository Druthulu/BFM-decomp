# Strip a ledger for a public copy: scan every string by JSON path first

When: publishing a JSONL ledger (restruct, delever) that may carry ROM-derived disassembly.
- `tools/ledger_backup.py --scan` walks every string of every record, keyed by JSON path (list indices collapse to `[]`), and counts predicate hits per path. Drop list = the paths with hits plus the plan's fixed list; bake it into the tool and its --help.
- The predicate is audit_public's DISASM_RES plus hex word + mnemonic, register-first-operand mnemonic lines, and `$reg` tokens. The `$reg` rule also matches C pin annotations (`__asm__("$2")`, `/* $s0 */`), so in 3.40 it also dropped delever `before_text`/`after_text`/`source`. That over-drop is safe but costly; to keep the C bodies, narrow it (skip `__asm__("$N")` and comments) and rerun.
- audit_public cannot read inside a gz, so the tool re-zcats its own output: every line parses, the count equals the source, 0 hits, < 50 MB.
- Deterministic gzip: `gzip.GzipFile(filename="", mtime=0)`, so a rerun on an unchanged ledger leaves the bytes unchanged.
- kit_lint (make tools-health) refuses the project name ("BFM") in a config/tool_dictionary.tsv description; word the row generically.
