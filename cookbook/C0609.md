# A source census's "untyped argument" rests on the tree's prototypes, and they are mostly void *

Measured 3.45 T14 (struct_twins --sources, c1 524f73e6ba -> c2 a2653e5165):
- c1 counted any argument to a callee with no C body (PsyQ, gte_*) as an untyped slot: 26,348 judgment sources.
- c2 typed bodiless callees from the prototypes in scope (TU externs, visible headers, include/psyq/*.h): only 139 moved.
  The tree's own SDK prototypes declare `void *` slots; only 1 arg-out flow resolved to a struct via a prototype.
- A kept-cast macro (CAST_SIGN/WIDTH/ALIAS/MISALIGNED/NONSTRUCT) parses as a call in type_census's flows: exclude
  tc.KEPT_MACROS callees, they are form-K casts, not untyped slots (about 4k sources were judgment on that alone).
Lesson: before trusting a judgment reason, break it down by the callee kinds that produce it; the "obvious" cause
(missing prototypes) can be a small share. Untyped SDK slots are a typing-wave input (DECL-PARAM, 3.44 sig census), not noise.
