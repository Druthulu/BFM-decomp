# Per-source split of a 7,000-source placeholder: chunked dry runs, union-read untypeables, padded gap variants

Context: P3.45 T17.c21 split Unkstruct_800B5CB8 per source across actor/sprite/model/fx/small (9,317 of 11,415 moved).

- Dry run of one 7,000-source keys line takes ~100 min and stops at the first refusal. Split the keys file into 16 chunks,
  keeping each member-token set in one chunk, dry-run in parallel (~30 min; 14/16 clean, 2 causes found). Write as 2 lines
  (slow chunk apart) so one refusal cannot sink all (7,917 s). Scripts: .run/3.45/t17/c21/big/chunk.py.
- A moved source whose union member is read into a local later used as a pointer (`v1 = p->unkD0.val; *(s32 *)v1`,
  `sv = p->unkC.i.hi.u`) makes that local an `arith` source: the gate's casts_untypeable rises (+18 for 8 sources).
  Find them by diffing the gate's untypeable source keys at HEAD vs tree; revert per key (c21/untyp/dump.py, revert.py). See C0634.
- A gap variant struct is padded to its alignment: s32 + s16 needs 0xC, so it "would not fit" a 0xA gap. Hold that source.
- The engine misses a typed local declared apart from its cast (`struct V *p; ... p = (V *)s0;`): it respells the cast only
  (incompatible pointer assignment, fields untouched). Grep the diff for bare `= (Parent *)x;` renames; hand-fold or revert.
- Pre-declaring a fixed-point union whose `val` slot is itself a sign union
  (`union { union { s32 s; u32 u; } val; struct { u16 lo; u16 hi; } i; }`) lets the engine join 16-bit half reads onto a
  parent field that was a sign union (fx unk34): the second attempt for "fixed-point vs halves" refusals.
- Deleting header definitions shifts survivor cites: rerun the recite script (c12/recite.py) before the gate each batch.
- Harness: struct_twins re-execs under .venv when rabbitizer is missing; scratch scripts importing it use .venv/bin/python.
