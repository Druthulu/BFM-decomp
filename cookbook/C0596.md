# Voiding an unused-return function fleet-wide: the unit, the joins and the traps

- Unit (R104 + C0571, 3.44 T7.c3): one definition site plus its binaries; JOIN the units of one name that share a
  declaration file (a src/shared/ov/*.h declaring it for up to 141 overlays), then void the joined group all-or-nothing.
  A group is blocked when one of its declaration files also serves a binary with no unit of that name (SHARED-DECL-SPLIT).
- Result: 55 names / 1,924 defs / 39,800 decl lines void; fallbacks: C caller uses the value (`void value not ignored`,
  e.g. `return f();` in a non-void caller although the asm never reads $v0) 6 names; bytes moved 4; blocked 2.
- The census places md_* declarations on overlay definitions; a .d-based unit misses them and DECL-RET grows: rerun
  `sig_evidence --compare` after the edit and void those declarations too.
- Traps: a type-prefix decl regex matches `return f(...);` (exclude C keywords); each round from HEAD must first restore
  the previous round's files (`git checkout src include`) or stale edits give `conflicting types`; this gcc prints
  errors without the word "error" (parse `file:line:` minus warnings/notes); a failing object hides other units' byte
  diffs in it (fix errors first, then re-judge); commit thousands of paths with `mapfile -t P < list; "${P[@]}"`.
