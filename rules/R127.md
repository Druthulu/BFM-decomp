# R127 — A tool change ships with its wiring and docs; no audit fan-outs
id: R127 · group: - · status: active · tags: tools,docs,wiring · origin: legacy memory, Drew 2026-09-02 · added: 2026-10-14

A tool created or changed ships in the SAME commit with: the sibling tools wired to call it (or refuse without it), its
dictionary row (R87), and its docs (`docs/ops/`, cookbook or playbook, whichever consumes it). Integrating a coder's or
agent's tool change is a tool change: the merge owes the same three; a law in the agent's report goes to the cookbook,
not the commit prose. No end-of-phase documentation audits by agent fan-out: asked "are tools/docs up to date?", answer
yes or no from what was done, with examples; cheap deterministic checks (`make tools-health`, an index `--check`) only.
provenance: legacy memory tool-change-updates-siblings-and-docs (Drew, 2026-09-02, S74: a 9-agent audit burned ~1M
tokens to answer a yes/no; five agent-merged tool changes shipped with no docs).
