# R121 — Phases name the counts they move and publish them at close
id: R121 · group: - · status: active · tags: - · origin: developer 2026-09-30 · added: 2026-09-30

Phase publication rule. At planning time a phase plan names the counts it will move (each with what 0 or the target means, tested on the planning tree against the instrument that will gate it) and the task that publishes them. The closing task of every phase republishes the README and timeline numbers and advances story section 10 and retrospective section 7 from the decision log. Cost data is not part of this: only the PhaseEnd's agent-runs slice that the PA3 method requires.

Why: P38's gate asked for a count the census defined as impossible (found at T5, after the work was planned), and the README, timeline and story had no task that refreshed them, so the numbers and the reasoning sat only in scratch and transcripts.
