# R124 — Raw cast residue is covered per site by a cause-named RESIDUAL row
id: R124 · group: - · status: active · tags: casts,residue,ledger,restruct · origin: PhaseEnd_Phase3.39 binding · added: 2026-10-02

A raw P/I/X/M site not respelled is covered only by the body's latest rung-S ledger row naming its cause, matched per site on (form, normalised base, off), never on line (`restruct.residue_match`). A `--residue` row for a body with an existing latest S row merges (keeps KEPT/MEMBER entries and verdict). TYPE-NOT-CANONICAL is residual for rung S; global I/M sites go through `--recipes --forms I,M` first and are residual only with the refusing recipe as cause (R2-*/R3-*).
