# T5 — every phase plan ends with a docs task: the public record, every moved series and README graph, and the phase's lessons in the day-1 guide and wiki.
id: T5 · group: - · status: active · tags: - · origin: developer 2026-11-12 · added: 2026-11-12

Every phase plan ends with a phase-close docs task, run after the milestone gate and before the close:
- the public record (story, retrospective, wiki, README) advances to the phase;
- every series, chart and generated doc the phase's work moves is regenerated, and the README graphs show it; a new kind of work gets its own series and graph in the same phase;
- the phase's lessons (what we would do differently, the retrospective's "sooner" clause) are written into the day-1 guide (docs/how-to-ai-decomp/) and the wiki (Start-a-new-decomp-project, How-to-AI-decomp), so a new decomp started from the kit gets them on day 1.

Why: the developer, 2026-11-12. Phase 3.43 wrote its lessons into the retrospective only; the day-1 guide had no naming advice and no chart tracked names.
How to apply: the planner adds the task (or extends the existing phase-close docs task) as the phase's final tasks; the plan lint and Claude check for it before presenting a draft.
