# §P39 T10 — 2026-10-02: type_census --check-casts --residue; restruct --forms / per-site --check-residue

- `type_census.py --check-casts --residue`: a raw P/I/X/M census site (not include/common.h's `#define` lines) passes only when its body's latest rung-S ledger row (`ledger_latest`, R100) has a `RESIDUAL(<cause>)` entry with a non-empty cause, same form, normalised base and off (`restruct.residue_match`; one entry covers one site; never by line). Line: `check-casts: raw P=… I=… X=… M=… (uncovered P=… I=… X=… M=…); macros … (unbacked n); lying=n (ledgered n)` + `by-cause: <CAUSE>=n …` (covered sites, desc). Exit 1 on any uncovered, unbacked macro site or unledgered lie. Forces `sites.jsonl` (as `--sites`).
- Writes `<out-dir>/residue_census.{json,txt}` (default `.run/P37/census/`): covered/uncovered by form, by segment (ov `ov_*` / md `md_*` / main / else shared, `restruct.matches_only`), by cause; top 50 map types by covered sites (sites, bodies); TYPE-NOT-CANONICAL sites, distinct types, and types needed to cover 50/80/95%.
- Without `--residue`, `--check-casts` is unchanged (T2 line; exit 1 on any raw > 0). KEPT macro sites (form K) are counted under macros, never residue.
- `restruct.py --rung S --residue --forms P,I,X,M --only <sel> --label <l>`: ledger-only rows for uncovered sites of the forms (default `P,X`); a body with a latest S row gets a merged copy (MEMBER/KEPT entries kept) plus one `RESIDUAL(<cause>)` per uncovered site. `--check-residue --forms …` counts uncovered PER SITE (not per body).
- I/M causes: ABS-ADDR (base bclass abs/gaddr: fixed or symbol address), GLOBAL (bclass global); else the P/X causes (FILE-SCOPE, NO-TYPE-IN-MAP, TYPE-NOT-CANONICAL, TYPE-NOT-VISIBLE, site_class).
