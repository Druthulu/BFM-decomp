## What the residual really was (read from the compiler, not guessed)

1. `expand_divmod` (tools/reference/gcc-2.7.2/expmed.c:3034-3057) emits K=const, B=`smulsi3_highpart`, C=`op0>>31`, D=`t2-t3`

2. loop.c therefore gives B and C the same `invariant_p` verdict (loop.c:2745-2750). If B is a movable, `force_movables`
   (loop.c:1193-1228) links K to B: `m1->lifetime += m->lifetime; m1->savings += m1->savings` (**doubling**, not `+= m->savings`)

   dump `dl/v1.i.loop` reproduces it line for line.
3. Any life-1/sav-1 movable is **not desirable** here (29 < 37): the 0x800000 const and `addiu $sp,0x20` print "not desirable".
   So the sra can only hoist if pooled/forced (needs B movable) — and a hard-reg dividend (scan_loop:596 forces
   `n_times_set[hard]=1`) kills B, C and D alike. **From one division of one register the target split is unreachable** — the
   S71 proof was right about loop.c; the lever is in a different pass.
4. The pass that can make the mult and the surviving sra read DIFFERENT registers is **cse**: `canon_reg` never rewrites a hard

  REGALLOC-PERM, `v7a`). $2 is ever-live anyway and dead in the copy→mult window → closeness 4 (`v8d`).

  this insn` BEFORE cse ever sees it (`v6`: store gone in `.cse`, sra back inline). An `__asm__("" :: "r"(sign))` feed keeps it but
  adds +2 weighted refs (flow.c:2067 `reg_n_refs += loop_depth`): sign 7 refs/39 insns vs half 7/44 → `allocno_compare`

  sign = 5/38 (.263) lands exactly between half (.318) and base (.2) → the target's j,mod,i,half,sign,base,arg0 = $s1..$s7 (`v9`, MATCH).

## Generalizable lessons (cookbook candidates)
1. "Hoist ONE insn of an expand_divmod chain" = a CSE-quantity split: `hard = x; ... hard / K` + an earlier pseudo-side
   `x >> 31` in the same cse path; pick a hard reg that is already ever-live and dead in the window ($2) so regalloc is untouched.
2. A movable's `forces` link DOUBLES the forcer's savings (loop.c:1226 `m1->savings += m1->savings`) — read the dump's
   "savings N" against that, not against `+= m->savings`.
3. To keep an otherwise-unread store alive through jump.c without perturbing regalloc, use a dead initializer (0 refs after
   flow) instead of an asm feed (+loop_depth refs, shifts allocno priority).
4. `regs_ever_live` is computed by flow BEFORE combine: a pin that combine later erases still steers global.c pass 0.
