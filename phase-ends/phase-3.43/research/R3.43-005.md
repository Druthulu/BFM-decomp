## Answer

No public source found names functions or variables for this game. Named or labelled RAM addresses exist only in three places: an NTSC-U CodeBreaker cheat list (26 named cheats, 50 address/value lines), ad hoc TASVideos forum labels (about 10 addresses, unverified), and the Druthulu/BFM-decomp repository, which publishes aggregate counts but no symbol list in the pages I could read. No Data Crystal page, no Archipelago apworld, and no gamehacking.org listing turned up. The debug menu is documented only in search snippets, because the TCRF article would not load. For a naming phase that must cite evidence, the usable public evidence is thin: the decomp's own code and strings, plus live RAM observation on a USA disc.

## Findings

- **The Cutting Room Floor** (https://www.tcrf.net/Brave_Fencer_Musashi, fetched 2026-11-10): the fetch returned an AI-directed block instead of article text. new.tcrf.net failed DNS, and www.tcrf.net later returned HTTP 526. Subpages (debug, prototypes, unused content) were not reachable. Search snippets only: debug menu entered with an L3 combination in the Japan Demo, Japan, and USA versions, navigated with D-pad and Circle; unused music noted. No variable or function names seen. Treat as unverified.
- **Debug menu discovery** (https://www.vgfacts.com/game/bravefencermusashi/trivia-15676, search snippet only, 2026-11-10): says the menu was found on a demo disc in 2021 and later run on retail via a GameShark code. Not opened.
- **Data Crystal** (https://datacrystal.tcrf.net/wiki/Brave_Fencer_Musashi, fetched 2026-11-10): HTTP 404. No RAM or ROM map exists at that title. Search for a RAM map returned other games only.
- **Archipelago**: searches for an apworld or randomizer returned nothing relevant. The only hit was a community randomizer list (https://github.com/video-game-randomizers/rando-list), which was not opened. Not verified against the Archipelago repository. Status: NOT FOUND.
- **Almar's Guides, CodeBreaker NTSC-U** (https://almarsguides.com/retro/walkthroughs/ps1/games/bravefencermusashi/codebreaker/, fetched 2026-11-10): 26 named cheats, 50 address/value lines, USA region stated in title. Names include Infinite Cash (80078E8E), Quick Level Gain (80078F08), Max Body/Mind/FUS/LUM (80078EE4 to 80078EFC), Infinite HP (80078EB2), Infinite BP (80078EB6), Have All Techs (800AE658), Invincible (30126C00), Stop Valve Reset Timer (801204A8), Time (80078E7C). Several entries are incomplete ("0???" placeholders, Joker Command). The page is a CodeBreaker list, not GameShark. Copyright 2008-2026, no author or publication date, terms link only (text not shown).
- **GameShark list, GameRevolution** (https://www.gamerevolution.com/guides/31036-brave-fencer-musashi-ps-cheats, search snippet only): fetch returned HTTP 403. Snippet names infinite HP, BP, cash, quick level gain, and all rescues complete. Not verified.
- **gamehacking.org**: not returned by any search or direct URL attempt. Status: NOT FOUND.
- **TASVideos forum topic 10034** (https://tasvideos.org/Forum/Posts/407103, fetched 2026-11-10; posts from 2010 and 2015-2016): forum-posted labels, not a map. RNG is 4 bytes at 0x00078980. Character position at 0x00126BF0 (X), 0x00126BF2 (Y), 0x00126BF4 (Z). Spawn point at 0x00126BF8, 0x00126BFA, 0x00126BFC. A 4-byte block 0x00126BF6 to FA was tied to a warp trick. Speed addresses mentioned but not given. No license stated. Forum posts are not verified against a disc.
- **speedrun.com** (https://www.speedrun.com/bfm, search snippet only): categories Any%, Perfect Ending, Glitchless. Resources page not opened, so RAM-watch lists there are unverified.

Claims 363,677 of 363,677 functions byte-identical, 218 binaries rebuilt, 350,530 functions in C, 1,256 PsyQ library functions. The repo contains no game data. Named symbols are not published in the pages read: the wiki lists no RAM addresses, symbol names, or debug menu content. config/ holds .sha check files and a ghidra/ folder whose contents were not listed. License: tools/ and docs/ are AGPL-3.0, src/ asserts no license (see src/NOTICE.md), third-party components keep their own licenses. The repo is not affiliated with Square Enix.
