Decisions:
- binding: type identity is decided by object evidence, never by bytes. A map type folds onto an existing canonical type only with evidence that both name the same object: E1-lineage (same union-find cluster, the drift name of a canonical cluster), E2-anchor (both anchored to the same global address, e.g. `&D_8011F7A8 + k`), E3-copy (field-wise copies at equal offsets between the two). Equal layout without a shared object is a coincident twin: kept apart and listed in docs/struct-twins.md `## Twins` (`struct_twins.py --census-dir .run/P37/census --write`).
- binding: a map type without entity evidence for an existing type is defined under an address name: `Unkstruct_<address of a function or global that owns it>` (suffix `_2` on collision), never under its cluster hash (hash names drift between census runs). Home file: include/struct_types.h for overlay and map types; src/shared/engine_types.h only for engine types already homed there. Each decision is a row of config/type_folds.tsv (`map_type action target evidence note`); restruct.py reads it, no typedef aliases.
- binding: a map type stays residual (a `residual` row, its cause the target) when no single struct can be written honestly: TYPE-UNION (conflicting widths at one offset; needs a union), TYPE-NO-LAYOUT (no consistent layout, size 0), TYPE-SCALAR (one scalar field; not a struct), TYPE-INTERIOR (base points inside an object, negative offsets), TYPE-NO-MEMBER (a def that rung S drew in 0 bodies; def pruned, would be dead). Sites of drawn canonical bases that still cannot be respelled keep the site causes (NO-FIELD, NO-EDIT, INDEX, GADDR, GLOBAL, TYPE-NOT-VISIBLE, POINTEE, AGGREGATE-FIELD).
- binding: defining a type does not move by-cause; every decision batch ends with rung S over the touched bodies, then `--residue --forms P,X,I,M` (new rows) AND `--residue --restamp` (rewrites stale TNC stamps) per segment, census before restamp, then `--check-residue`.

Gotchas:
- generalizable: `struct_twins.py` defaults to `.run/P38/census` (stale) while `--check-structs` reads `.run/P37/census`: pass `--census-dir .run/P37/census` or the doc is regenerated from an empty dup_gating.tsv and the gate does not move.
- generalizable: `restruct.py --residue --restamp` only restamps; it writes no rows for newly uncovered sites. Run `--residue` without `--restamp` too.
- workflow: restruct_cycle.sh has no zero-work exit; with an ONLY set whose remaining bases are non-canonical it re-plans the same 50 files forever (t2_rS4..rS21: 0 sites, 996 skipped). Stop the cycle when a batch reports 0 sites and 0 written.
- generalizable: hash-named map types (Unkstruct_<hash>) are cluster hashes and can change when the census sees new bodies; decisions key on them but define under address names.
