## Method
- Caller $aN source from objdump of the matched build objects (`.run/P40/T7/c1/argsrc.py`, cached disasm `.run/P40/T7/c1/dis/`): PASS = reg untouched from caller entry to the jal → the caller passes its own param N (a `(void)` stub caller gets the param = cascade).
- Caller edits by hand, interim K&R `()` decls (and K&R def head where a call follows the def in the TU), per-binary `make check`, scratch pre-check of each def body (apply, check, restore), check-all, commit; then rung D per def: `.run/P40/T7/c1/rd.sh` = `delever_oracle --calibrate ov_SC04_011 ov_SC03_015 md_SC07_004 main`, `restruct --apply --rung D --callee F --body B --label t7c1_<f> [--tu TU | --all-defs --map-data]`, commit. Cascade stubs whose decls span the fleet: signature-only rung D (`rds.sh`, `--signature`, `--tu <header>`).
- Body form (`mkbody.py`): pin line dropped; when the pin var is used only by a `T x = pin;` copy, the param takes the copy's name/type and the copy is dropped (needed for 8017D254, 801811A8, 8017F258: the copy kept as a second pseudo moved s0 / grew the frame).
- Deviation (tool mechanics): restruct --apply refuses a dirty src/ (R42) and an oracle calibration older than HEAD (R56), so each rung D run is its own commit; check-all ran per batch on the caller commit and again after the batch's rung D runs.
