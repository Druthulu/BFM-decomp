## Walls (with evidence)

- func_8017E4E0 — WALL local-alloc-const-qty, best 11 of 125. The -0xA0 constant pseudo
  has 3 refs and the shortest live range in the block, so local-alloc's qty priority
  (floor_log2(n_refs)*n_refs/live_length) gives it the first colour $2 and merges it
  into the same qty as 0xA0/-0x78/0x78; the 12th byte pseudo (range spans the const
  block) is pushed to $3. The target has the -160 in $3 (a hard reg) and the constants
  in $2, so the const pseudo must be a separate, lower-priority qty — only a hard
  register does that. Tried: c1's assignment at all 13 byte-group positions (s32/s16),
  before/inside/after the const block, 4 const-block orders, do-while(0) wrapper, one
  variable per constant, decl order, literal -0xA0 twice, struct-pointer temp. All 11.
- func_8017D3A0 — WALL local-alloc-const-qty, best 11 of 60. Same mechanism as
  func_8017E4E0 with struct-typed stores; the allocation is identical (11) whether the
  stores are `*(u8 *)(p + off)` or `((Unkstruct_8017D3A0 *)p)->unkXX`.
- func_8017FB50 — WALL global-alloc-nrefs-prio, best 2 of 48. The two out-pointers have
  5 refs each (1 set + 4 uses) and the first RotTransPers result has 2, with comparable
  live lengths, so global-alloc's allocno_compare gives $16/$17 to the pointers and
  pushes the result to $18. A 16-bit `tmp` shortens the result's live range (the
  truncation pseudo is short-lived) and the callee-saved assignment becomes exactly the
  target's (s0 = tmp, s1 = flag_out, s2 = p_out) — but the value then needs a
  sign-extension pair (sll+sra) at the func_801823D4 call where the target has a plain
  `move a0,s0`, so the body lands on 2 and not 0. Also tried: declaration order, the
  pointers as s32 ints, flag_out spelled `p_out + 1`, the pointers initialised at the
  top of the function (28), u16 tmp, `tmp == tmp` (12).
- func_8014CF04 — WALL reload-second-base, best 22 of 61 (the structurally closest
  lever-free body, the plain unpinned one, is 34). Unpinned, GCC keeps a second address
  base q-1 (`addiu s2,s0,116`) and uses it for the four negative offsets and the
