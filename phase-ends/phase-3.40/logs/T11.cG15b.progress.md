## Gotchas

- `sched1`'s RTL chain is the REVERSE of the launch order: a LAUNCH_PRIORITY boost
  (7f000001 in the `.i.sched` trace) pushes an insn LATER in the final code.
- A `do { x = x; } while (0);` survives as a real second set only for a HARD-REG-BOUND
  variable (a register variable); for a normal local cse removes it (func_80190D70's
  `vol` case).
- A compound assign on a value only preserves the value if the surrounding expression
  already masks it (`vol | 0x3000` then `& 0xFFFF`); otherwise the mask must move and
  the instruction order changes.
- The `SCAN` item is a census pseudo-body (a source region), not a function; the scorer
  compares the whole TU object (3991 ins).
- `hdump.sh`/`cc1_dumps_tu.sh` need an absolute `DUMP_ROOT` under the item dir; the dumps
  were deleted after reading (the shard dir is 832 KB).
