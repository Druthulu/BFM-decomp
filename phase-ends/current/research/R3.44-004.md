Cookbook entries (rule, max two lines each):
- C0543: Change a return type as one unit (def + all decls + callers); a def retyped alone breaks every extern decl. The return type is a byte fact at the caller; type_census counts only parameter lies, so lying=0 does not mean no return lies.
- C0547: Void->int retype on a decl is not always byte-neutral (a dropped call result still sets $v0 and moves regalloc); gate the full fleet, bisect by object compare, revert the culprit fleet-wide.
- C0548: Clear return lies fleet-wide: decls to def, else def to decls, else ledger; width/sign lies stay ledgered.
- C0552: Detect return lies by comparing normalised return spellings (argcheck norm_ret, opt-in returns=True); arity alone misses them.
- C0567: Give a return-less non-void def a real return only in a byte-neutral form (tail call, $v0-resident value, kept local); otherwise a `$v0 at exit` comment.
- C0384: decl_prior's fleet majority can be a propagated mistake; read the rivals and the asm, which decides.
- C0508: A byte-proven K&R or pin-faked argument is a unit of definition plus callers; a definition in a shared header makes the byte fact per-definition.
