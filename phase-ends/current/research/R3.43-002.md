Key facts for the 3.43 plan:
- rename_sym accepts func and data rows only. type/field/local rows fail at edit_symbols (no symbol line, not a placeholder).
- rename_sym never validates kind, basis, confidence, evidence or citation; it writes them to names.tsv verbatim. rename_scan --ledger catches bad values later.
- Demoting a curated name (Foo -> guess_Foo) appends a new names.tsv row and leaves the old Foo row in place. That old row becomes a dead row.
- No tool maps a docs/leverage.tsv key (h_exact[:12]) to a dedup group id or to its member list. The join is by prefix against classes.jsonl plus .run/sig.<alias>.jsonl.
- rank43 is recomputed from scratch each run. Score does not depend on names, so rank order is stable; rank43 renumbers as named rows drop out.
- rename_sym rewrites docs/leverage.tsv textually (no generated marker in its first 3 lines). leverage_rank --check then fails until regeneration.
- leverage_rank refuses to run when src/ or include/ changed since the census head. A names rename that touches src/ triggers this; re-run tools/type_census.py first.
- `rename_scan --ledger --gate-citations` fails today (1,083 curated without citation).
