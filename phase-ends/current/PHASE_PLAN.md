- A new tool, three lines (house rule §3). What it does: decodes each distinct body once and follows its control flow to measure $v0 reads after calls, the argument registers and stack slots a callee reads, each call site's argument setup, and narrowing around calls. What exists: argcheck and type_census compare C texts (R3.44-002); tools/sig_image.py decodes the original bytes into function boundaries, h_exact hashes and jal targets with rabbitizer (:34-37); tools/decl_from_use.py has a MIPS-I word decoder and a linear register scan for data externs (:130, :188); m2c needs a supplied signature (translate.py:4692) and decompiles whole functions. The delta: a control-flow graph with delay slots and a $v0/$a-register liveness pass over the sig inputs, and the comparison with the C through argcheck's parsers. The milestone names the tool.
- Rows by h_exact (share_census.py:12-13): one byte body has one callee contract; its callers are the union over every instance's binary. A call from an overlay or module into main or resident resolves through the target binary's sig rows.
- The evidence bar: `used` needs a cited read of $v0 on some path after a call before $v0 is written; `unused` needs every call site known (no jalr exposure, the address never taken) and none reading; anything else is `unknown:<reason>`. Width and sign evidence is recorded with cites and decides nothing alone (R3.44-001). The census never reads the C.
- "Agrees with its measured contract" is the rule table T4 writes (docs/ops/sig-evidence.md, a selftest per rule) and the developer sees at T4's review. The planned reading: a definition or declaration disagrees when it contradicts a measured fact (a `void` return that a caller reads; fewer parameters than the callee reads; a declaration that differs from the definition); a `()` declaration is not a prototype, so under "one shared prototype" it is replaced (T6) unless ledgered; an unused parameter or an unread non-void return contradicts nothing. K&R definitions stay where the table finds no contradiction: their heads are byte-true (C0508:1).
- Marked casts: rule R123 lets a kept cast be spelled only by a registered include/common.h macro backed by a ledger row; the registered macros are memory-access forms (include/common.h:69-78), so the call-site view needs one new registered macro, introduced by T5 after a one-callee probe and recognized by type_census's KEPT forms (:143-145). If no cast spelling keeps a direct `jal` (a cast function designator may compile to `jalr`), T5 returns `question` with the alternative (an asm-label alias declaration naming the old view, C0223).
- One exception ledger for the gate: config/lying_exceptions.tsv gains a cites field or moves into the new ledger, with type_census's loader (positional fields 0-2, :2044-2055) kept working in the same commit.
- tools-health: the gate runs after type_census (Makefile:317); target at most 5 min at -j 16 (tools-health is about 19 min).
- Effort: T3 is the one `effort: high` task: what counts as a read, when the census must say `unknown`, and how tail positions and address-taken functions resolve are judgments no test fully arbitrates, and every later task copies them. T4's rule table is judged at its review.
