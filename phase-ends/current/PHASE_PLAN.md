## Rationale
- Types before levers: rung S re-sweeps respell thousands of bodies; lever cracks after that run on the final body text, so no crack is redone. Types may also explain pins (the 3.39 premise).
- The canonical-types campaign is mechanical and tool-driven (write-types, rung S, residue rewrite), comparable to 3.39 T3+T4. It is pilot-gated: T2 measures conversion rate, header fan-out cost and new causes on the top 75 types (50% of TNC) before T3-T5 fan out. Planner judgment: TNC 0 is realistic in one phase if T2's pilot converts at T3's rate. T2 returns `blocked` with a projection if it does not.
- The literal lever 0 is agent-priced. About 800 crack targets remain after the cheap tools ran dry (3.39 T8: 0 pins removed by delever R/E/G). The comparable legacy P36 lane took 9 sessions and about 15-20M tokens. The plan goes class by class, cheapest real fix first:
  - T8: re-judge 1,013 not-judged/author-left rows with the oracle; the GTE, asm-macro and asm-body classes;
  - T7: missing-parameter pins become declared parameters, a signature fix through rung D, as with 3.39 T6 lying decls;
  - T9: head-class cracks, where one crack propagates to every copy;
  - T10: a singleton pilot that measures crack rate and cost;
  - T11: the singleton wave at the developer's cap.
  T10 is the checkpoint: if its projection exceeds the cap, it returns `blocked` with numbers and Claude puts the milestone to the developer (see Developer decides).
- T2 is `effort: high`. Its judgment: the fold policy for map types, meaning when two hash-named layouts are one entity (fold onto one canonical) and when they are coincident (separate types). Also which canonical name and file each type gets. Bytes cannot arbitrate type identity. 1 high task in 14.
- Legacy-T7 items (T6) come before the missing-parameter bulk (T7): the func_801A1E94 pair is a missing-parameter cascade, and its fix is the template for T7.
- T12 (timeline uncovered series) runs right after T1 so every later snapshot draws it. T14 carries the standing phase-close docs request (developer 2026-10-02).
- Every task that respells bodies leaves the per-site cast gate red (C0528). Each such task re-runs `restruct --rung S --residue` for its segments before it is done, and T13 re-runs it fleet-wide.
