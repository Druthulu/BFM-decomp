Summary: The project now has a measured answer to "which names buy the most readability": every function body (one per share class) and every data address is ranked by how many places in the deduplicated source its name would appear, plus credit for struct types it anchors and a damped bonus for bodies shared across many binaries. Counting is per unique body, so the ranking stays put while bodies move into shared headers. Every one of the 3.36 million relocations in the build is accounted for, either to a unit or to a named exclusion, and three independent checks agree. 3.43's naming list is the top 500 of the units not yet named; those 500 cover about 35% of all references.

Decisions:
- binding: references = relocations of our own built objects, parsed in Python (REL addends); objdump -r is the independent raw-count control, never the parser.
- binding: units are one per share class (h_exact) for functions, `raw:<space>:<addr>` for a call target with no sig row that starts an ELF FUNC/global symbol, and (space, addr) for data; space = vram base of the image holding the address (main, resident, the slot base; `abs` outside every image).
- binding: score = (refs + own) x (1 + log10(fan)); refs = unique-body non-HI16 references; own = sum over held struct types of reach/holders; fan = instances (func) or referencing binaries (data). Reasons are in docs/leverage.md ## Weights.
- Struct types are a weight on data units, not a ranked kind: references partition over func and data units, so the top-N coverage is well defined.
- The 3.43 set = units with named != yes (rank43). Already-named: 32 func classes, 709 raw (mostly psyq), 243 data.
- Named exclusions (not nameable symbols): NONALLOC:.pdr, LOCAL-LABEL, JTBL-CASE, JTBL, UNLINKED-OBJECT, SLOT-CALL (call into a slot from outside it, no unique callee), TEXT-NOSIG (no symbol at the target), SECTION:.rdata, LITERAL.
Deviations:
- Fan factor changed from my first 1+log2 to 1+log10 after c1's data: the rank-1 class is a 2-instruction stub at 726 addresses (fan 11,852); log2 would multiply it by 14.5.
- c2's `nins` column held the instance count, and the md printed the census head (which tools-health rewrites at every HEAD, so `--check` would break after each health run). I fixed both inline (expert edit, under 10 calls): nins = body instructions for sig classes, blank otherwise; the head is kept only in the staleness guard; a column legend was added.
- `--check` also runs the objdump controls (c2), because the md records their verdicts; it takes about 35 s.
Findings:
- Relocations raw 3,355,973 = attributed 1,942,944 + hi16 661,181 + excluded 751,848; unique-body refs 1,146,245.
- Top 100 by score cover 14.8% of unique refs, top 500 37.0%; the top 500 nameable units (343 func, 157 data) cover 35.5%.
- Rank 1 is func_80014554's class (2 instructions, 726 addresses, 177 binaries, 8,622 refs): a fleet-wide stub. Ranks 2-10 are mostly 141-overlay shared bodies; the first datum is D_8011511A (resident space, owner Unkstruct_8011511A).
- Struct ownership is small next to refs (total own 33,239; max per unit about 146): no struct's reach rivals a hot function's call count once both are counted per unique body.
- sig rows 362,389 = .pdr relocations 362,389: one procedure descriptor per signed function instance (a free cross-check).
- 8 holder names resolve to no data unit (5 suffixed names like D_801C7E34_tbl, 3 slot addresses); 172 typed sites map to no body (168 macro definition lines, 4 no address). Both are printed by the tool.
- Control symbols are chosen automatically: highest-ranked, refs >= 20, name unique fleet-wide, every referencing body single-instance (today func_80181048 49, D_800760B0 54).
Gotchas:
- generalizable: sys.exit in a multiprocessing.Pool worker hangs Pool.map; raise instead (C0560).
- generalizable: an objdump-grep control needs a fleet-unique symbol; objdump -r lacks REL addends; main's map overlaps NOLOAD psyq .nl_* with asm data; ABS symbols are real (C0561).
- generalizable: a generated doc under a byte-for-byte --check prints no volatile provenance; a new docs/ file needs a docs/wiki/Reference-index.md row or doc_links says UNCOVERED (C0562).
- harness: `make tools-health` regenerates .run/P37/census at the current HEAD; leverage_rank refuses only when src/include changed since the census head.
