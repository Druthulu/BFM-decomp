Status: question | expert: pa-expert | ctx-at-completion: 95k | commit: 231f3e07af (+ this task's commit) | coder runs: c1 in-house done (ef8da51d64), c2 in-house done (16f4a4934c, 231f3e07af)
Done: tools/sig_evidence.py measures every function class's return use, arguments and width evidence from the original bytes over all 218 binaries in about 17 s, deterministically, with a 29-check selftest; rules and reasons in docs/ops/sig-evidence.md.
Summary: The project now has a tool that reads the original machine code of every function and records, with the exact instruction as proof, whether callers use its return value, how many arguments it reads and its callers pass, and any sign that a value is a byte or a short. It is the measured contract that the next tasks compare the C against. Hand checks against the disassembler found one real bug (calls from modules into overlays were missed), which is fixed. One control in the plan assumed something the bytes contradict, and 146 functions in main and resident are missing from the tool's input; both need a decision.

Decisions:
- The rule doc was written first as the spec; the coders implemented and amended it (all amendments recorded in it).
- Instances come from the sig files (IMPORTED and nins 0 out); names from the alias's own symbol file, else the sig name; keyed (binary, vaddr) (C0571).
- jal targets resolve through the caller's splat symbol stack; a target outside every stack image resolves fleet-wide by function start (one class credited; several -> `cross-binary target unresolved`) (rule OUTSIDE-STACK, C0585).
- `unused` is strict: an address-taken function (its start as an image word, or a lui/addiu|ori pair, in any binary loading with it) is only `used` or `unknown`.
- Reasons 1-8 decide `ret`; `frame unresolved` and `no width evidence` live in `args.reasons` (else no class with no width evidence could be `unused`).
- lwl/lwr write rt without reading it (C0583); an outgoing $sp+16+4k store counts as a stack argument only if never reloaded, below address-taken locals, contiguous from $sp+16 (C0584).
