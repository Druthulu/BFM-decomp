# T15 — the typing engine: pointers typed at their source, casts spelled as member accesses

Done: `restruct.py` rung T (`--type-source/--type-batch [--write]`, `--type-check`) types a param, param-copy, local, global, call return or struct field at its source and respells its casts as member accesses, judged on the bytes; the md_SC02_009 pilot typed 17 of 51 sources (46 casts gone), every gate green.
Summary: The project now has a tool that gives a pointer its real struct type where it is declared, instead of casting it at every use. It changes the declaration (and, for a function parameter, the definition and every declaration together), rewrites each cast on that pointer as a plain field access, adds a missing field where the struct has unknown padding, and keeps the change only when the compiled game stays byte-identical. Sources that need a person's judgment, such as a pointer read as two types or passed where an integer is expected, are listed with their reason instead of being guessed. A pilot on one small file typed a third of its pointers and removed 46 casts with all 218 binaries still identical.
