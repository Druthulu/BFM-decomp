## Design
- residue set = census P/X sites (`sites.jsonl`) in TUs matching `--only` (default `ov_*`, `matches_only`) whose `("S", tu, unit)` has no `ledger_latest` row; unit = `fn` or `<file-scope>` (site fn null).
- row: keys as rung-S rows; `fn` null + `addr` null for `<file-scope>`; nhash_before == nhash_after == current body nhash (`body_nhash`); for `<file-scope>` the norm hash of the whole masked file; None if body gone (0 such rows in t3_resid).
- site entry {form, line, base `bclass:base`, off, type, verdict `RESIDUAL(<cause>)`, cause}. cause order: FILE-SCOPE (fn null) → NO-TYPE-IN-MAP (type null) → TYPE-NOT-CANONICAL → TYPE-NOT-VISIBLE → `site_class(s, None, typed=True)` (MISALIGNED / NO-EDIT).
- body verdict: the single shared cause if in `S_NO_EDIT_VERDICTS`, else RESIDUAL. bases carry the cause as `status` → `s_judged` False → not in `ledger_index` done, `s_finished` unaffected (selftest asserts both).
- rows sorted (tu, unit); sites sorted (line, pos).
