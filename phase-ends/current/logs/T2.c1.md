## Deviations
- Global owner: bss addresses (past an image's file bytes, absolute `A` symbols in the ELF) belong to the nearest image below in the stack
  (first run had 3425 "address in no image": main bss like D_80074818).
- global-view only for `(B *)&D_x` on the whole object: `&D_x[k]` (k != 0) and `(s32)&D_x + k` are not the object (spot-check found both).
- `global-view-if-refused` not a reason string: refused global-view links keep their cause (conflict/size) with sub `global-view`.
- hub "own accesses": parameter = offsets accessed via that parameter in its definition(s); global = via its name; return/member slots = none.
- Unions: width conflict = disjoint width sets at one offset, partial overlap not covered by the same side, or disjoint load signs.
- Extra summary line: pointer-flow outcomes (diagnostic for the low pointer counts).
