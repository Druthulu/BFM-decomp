## Deviations / readings
- "dereferences it": param deref, or the single-source typed local it is assigned to is dereferenced.
- Typed uses: struct casts only; scalar casts (`*(s32 *)(p + 4)`) are accesses, not typed uses (not "mixed").
- Poly refusals 0 under every policy: no struct-bound argument reaches any of the 268 poly slots (PF has no arg-eff/poly outcome).
- Cast views do not feed width maps (c1's lexical chains need a bound identifier), so arg-eff/view merges are vetoed only by the
  bound sides' accesses and size facts.
- class for no-evidence / undisposed is `-`; apart classes own|conflict|size|hub; singleton precedence conflict/size/hub (first
  refusal in order) > own.
- c1 table names (links.tsv etc.) replaced by per-policy names.
