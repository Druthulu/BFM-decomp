  cc1 errors from the asm check are the backstop (respell from cc1 line + member). `#line` files report mapped lines.

- xargs -P output interleaves lines: probe via a Python pool collecting per file (w/gp.py).

- Retarget notes go before ` applied:<hash>` (row must end with the stamp).
- Kept REINTERP macros back by (tu, fn, line): w/kept.py appends merged rung-S rows with KEPT(REINTERP) entries from the census
  summary (`summary.casts.macro_sites`); a later line shift in those bodies unbacks them.
