## Moves that cracked

- **func_8018219C** (MATCH, score 0, 52 ins = target): the reused local `d` was
  split into one name per value (`d1` = the computed delta, `d2` = the `(s16)`
  truncation, `d3` = the shifted result).  Each is a single-death local, so
  local-alloc gives them $2/v0 in order — exactly the register the pin forced —
  and the in-place `sll`/`sra` chain of the target is reproduced.  No other change.
- **func_8017E5C4** (MATCH, score 0, 26 ins = target): the `obj` copy is dropped
  and the parameter is used directly.  The parameter is live across the call to
  `func_8017DEF8`, so gcc keeps it in a callee-saved register and copies it in the
  prologue (`move s0,a0`) — the target's $16 without a pin.

## Walls

- **func_8017E6EC** (best 6): the reused `t` split per value (`t1..t5`) plus the
  load/add split brought the score from 17 to 6 and the length to 172 = the
  target's.  `t1/t2/t3/t5` are single-death locals and take $2/v0 as in the
  target; the group `{case 2 def -> lab_e958 use, lab_e954 def}` is a GLOBAL pseudo
  (its value crosses the `goto`), so global-alloc gives it a register only after
  local-alloc has handed $2 to the block-local constant 0x10 (live 104..107,
  overlapping the global's 105..156) — the global gets $3/v1 and the constant
  $2/v0, the mirror image of the target.  The target's assignment is only
  reachable when the global is a hard register, i.e. with the pin.
  Splitting `c` per value, `u16`/`s16` widths, a `do { } while (0)` ref boost and
  the decl-order permutations (R4) all left the residual unchanged.
- **func_8018302C** (best 2), **func_80182ED4** (best 6), **func_801880E0 /
  func_801889B8 / func_801886B8** (best 29): all `cse-copy-merge`.  The target's
  copies (`move v1,v0`, `move s4,s0`, `move s0,s4`) are the materialisation of
  `plus v, $0` — a HARD-register addend, which combine does not fold, so cse
  cannot propagate the equality and the copy survives to the allocator.  Every
  C-level zero is a constant: combine folds `v + 0` to `v` and cse then
  propagates it, the copy disappears and the length drops by one or two
  instructions.  The panel walkers additionally have the $18 pin load-bearing:
  without it gcc gives the more-referenced `w0` the first callee-saved register
  ($19/s1) and `ot` the second ($20/s2), the target has `w` in $18/s2 and `ot` in
  $19/s1.
- **func_801815AC** (best 4): `q` is defined in both switch arms and used after the
  join, so it is a global pseudo; the block-local constant 0x9000 owns $3 in both
  arms (local-alloc runs first) and global-alloc then may not reuse $3 for the
  global `q`, which falls to $4/a0.  The target has `q` in $3 and the constant
  also in $3 (they do not overlap in life) — only possible with `q` a hard
  register.  Every instruction and the length (39) already match.

## Notes for the next reader

- The lever-free body of an item is `orig.c` minus the `register ... __asm__`
  line; `--explain <TU> <fn>` prints exactly that body's residual against the
  target, which is the fastest way to see what a candidate has to fix.
- An empty body (`c0.c`) makes the whole-object diff print the target's
  instructions — the cheapest way to read a target's register assignment.
- Two of the nine walls are the same mechanism as `func_8017FBCC` in
  `.run/P40/T11/moves.md` ("only v0+$0 keeps it").
- Left in the shard dir (removal was denied by the sandbox): `t1.py`, `extract.py`,
  `extract_all.sh` — helpers written before the command surface was known; none of
  them ran and none of them is needed.  The `c*.c` files are the scored candidate
  bodies (the `tries` column counts them).
