## Gotchas
- generalizable: a void→int def flip needs every agreeing decl and every non-extern `void f(...);` prototype flipped too, else "conflicting types" in TUs that include the shared def.
- generalizable: def flip to the lying side's type only when the lying decls are the majority; otherwise fix_ret rewrites the agreeing majority.
- generalizable: argcheck.lc.sc.mask_text keeps line count, not column offsets: map masked matches to raw by line.
