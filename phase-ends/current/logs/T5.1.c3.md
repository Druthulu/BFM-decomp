## Design (as coded)
- Index: canon headers parsed with `type_census.walk_file`; raw spans from `_walk`; shape per def (`_struct_shape`: scalars/ptr/arrays/nested, member names kept); position order struct_types.h before engine_types.h.
- Canon: SDK name iff layout == SDK layout (LIBGTE.H/LIBGPU.H from tools/reference/psyq-sdk, u_* -> u8/u16/u32) AND SDK evidence (exact member list, or same wildcard sig with a meaningful name) — layout alone is ambiguous (SVECTOR=RECT, CVECTOR=P_CODE, DR_MODE=DR_TWIN=DR_AREA=DR_OFFSET, VECTOR=RECT32). Else most-used name among defs with the meaningful sig.
- Canon body moves to the class's first def position (C0224); a later-defined type in its body is respelled to its own class canon if that lands earlier, else canon falls back to the first def (4 classes: ddfe48605de8, 51be9f07fb92, 5b95bca7ba8c, 5b8ad54bc29f).
- Others -> `typedef <Canon> <declarators>;` in place; `struct <Tag>` uses respelled fleet-wide; member accesses respelled from cc1 `has no member named` errors via `_rewrite_access` (same offset+shape node, constant indices only).
- Dry run: 123 classes (120 tier-1 + SDK groups MATRIX 141 tier-2, RECT 1, POLY_G3 1), 1488 def edits, 191 tags, 215 aliases with differing member spelling.
- SDK notes: `d4b0395bb0af:d75a25` (16B vx,vy,vz,pad) cannot take `VECTOR`: canon `VECTOR` is `{s32 vx,vy,vz}` 12 B (engine_types.h:1004), changing it changes a layout. `DR_TPAGE`/`DR_MODE` family classes carry no SDK member names.
