## Decisions beyond the brief
- A comparison against 0 / NULL is not a non-cast use (holds for any pointer; otherwise almost every source would be judgment).
- Mechanical with one cast type A and one flow type B != A: B is the parent (flows agree among themselves). Zero struct cast types (raw only) is mechanical only when the flows name exactly one type.
- gaddr sources are keyed `&name@binary`, apart from the value `name@binary`.
- Fit search k in {0} ∪ P's cast base offsets (no full pairwise scan); fit_score = accessed leaves / parent leaves.
- Flows in both directions (arg-in for a parameter, arg-out / assign-out / return for any param or local).
