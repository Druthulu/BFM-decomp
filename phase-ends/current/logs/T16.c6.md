  - parent s/u scalar: `void *` views map onto it; 16-bit half reads open `union { s32 val; struct { u16 lo; u16 hi; } i; } unkN`. Half signs come from the reads (two signs give a sign union in the slot; an unread half defaults to u16). The parent's own accesses become `.val`.
