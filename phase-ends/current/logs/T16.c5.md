## Engine (tools/restruct.py)
- `_fold_gaps`: a declared gap union is a named union field of the target that holds `u8 raw[<its size>]`. Its struct members are the class variants already placed; sign unions inside them are parsed too.
- fold_plan: the member's fields inside a gap are taken out of the plain merge and go into variant `<v>`. The variant is created if absent and joined if present; fields at the same offset with the same size and leaves are reused, and an overlap is refused. Fields are named `unk<absolute offset>`, with `u8 pad<rel>` padding between them. Accesses are respelled `p->extX.<v>.unkNN`. A field that straddles a gap edge is refused. A gap touched by a row that has no token is refused with "needs class variant".
- Evidence form: `member:extX.<v>`, one token per gap touched. When a gap has no token, the first token's variant is used for it. A token that names a non-gap union is the T6 path, as before. Documented in the fold-engine header comment.
- `_fold_gap_decl`: renders the union and refuses a variant that would not fit the gap or that would change its alignment.
- Sign-union join (needed when rows are applied in sequence): a scalar joins the target's committed sign union `union { u16 u; s16 s; } unkN` through its sign member. Inside a gap variant, two signs placed by the same call open a sign union there (copied bodies go on one batch line). `fsig` now compares nested members, so a changed union is re-rendered.
