## Traps (generalizable:)
- A shared-header edit (type deletion) must belong to every binary's bisect set, or a red non-main binary stays red after the bisect. Cost: cross21 took 3.2 h (every gated binary re-gated when a deleting class is undone).
- A batch tool that commits by directory list misses a directory it newly edits (include/); the dirty-tree guard must cover the same list.
- Copy name forms: sig name, aF<ADDR>, and `<any>_x(...) __asm__("func_<ADDR>")`; every name-keyed ledger (restruct rows, registry member names, lying def_file) must agree with the form actually written, or progress/check-casts/type_census drift silently while the byte gate stays green.
- type_census keys a param-include def by the site's TU, not the header.
- An in-tool post-check that runs before the ledger rekey cannot see a rekey bug: tools-health after the sweep is the gate.
