## Method
- Copy test: `.run/T6c3/fnhash.py F` hashes each built .o's `objdump -dr` body of F, with relocs and addresses normalised. Return path: `.run/T6c3/tail.sh F OBJ`. Uses per binary: `.run/T6c3/uses.sh F DIR…`.
