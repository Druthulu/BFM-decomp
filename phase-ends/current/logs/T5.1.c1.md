## Design notes
- Liveness is per name: roots = canon def/alias names (incl. typedef ptr_names, tags) appearing as any token outside CANON_HEADERS; a live name's defining canon def/alias adds its tokens ∩ graph minus its own names. So an unused tag of a used typedef (`typedef struct actor4c {..} X`) stays dead — same as the old reading for tags.
- `--check` counters untouched: `dead_canon_names`, `dup_layout_classes`, the four outside counters keep the old reading (render + --check + progress.py:1191).
- Twins match key = row lhash exactly (`<lh>` or `<lh>:opaque`); names compared as a set against the row's FULL name set.
- twins_stale = stale twin entries + stale dead-kept names. twins_listed / dead_kept count the VALID entries only.
- block frame = block-scope outside def with declares_object whose names are not in any gating row of the same base lhash (anonymous frames never are).
