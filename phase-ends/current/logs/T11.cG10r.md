  and the store's base change (21 and 5).

  the operand order of the address add (ours `addu v0,v0,a1`, the target's
  `addu v0,a1,v0`). The C tree is pointer-first, and gcc-2.7.2's combine
  canonicalises the commutative add to index-first for every spelling tried
  (pointer+int, integer+integer, both orders, temp introduced, temp inlined,
  decl-order permuted). Only the launder's hard-reg pointer keeps it
  pointer-first.
- func_8017D81C — `cse-const-holder` (new). The target materialises x/y/z at
