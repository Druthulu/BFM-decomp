Summary: Many functions were declared with empty parentheses, which tells the compiler nothing about their arguments. Each now carries the same full prototype as its definition, so a modder can trust it. A few declarations could not take one prototype (shared headers serving overlays whose definitions disagree, or a clashing wrong prototype elsewhere in the same file); those stay as they were, ledgered with evidence. Every build stays byte-identical.
