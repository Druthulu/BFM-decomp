## Lessons
- A failed cc1 still yields an identical object through the pipe: the FAIL list is the gate (C0589 confirmed).
- `conflicting types` with another prototype in the same TU is the main failure of a `()` -> prototype sweep: grep
  for other prototypes of the name in each TU before the compile.
- c1 calls.tsv counts a non-extern prototype line (`void f(s32 a0);`) as a call: skip declaration-shaped lines.
- commit_task.sh path list via xargs may split into several commits; pass a short list or check `git log`.
